หน้าแรก Basic Advanced Example File

Advanced: Logic Block, .NET Automation และ Offline Programming

เมื่อสร้างงานพื้นฐานได้แล้ว ขั้นต่อไปคือควบคุมพฤติกรรมของเซลล์ด้วย Logic และส่งออกโปรแกรมไปใช้กับหุ่นยนต์จริง

1. Logic Block คืออะไร

Process Simulate ใช้ Logic Block (Resource ประเภท Logic) ผูกกับ Signal ของอุปกรณ์ เช่น Gripper, Sensor, Door เพื่อกำหนดเงื่อนไขการทำงาน คล้าย Ladder Logic ของ PLC โดยไม่ต้องเขียนโค้ดข้อความ

ก่อนเริ่ม: สร้าง Logic Resource จากเมนู Modeling → Logic Block แล้วผูก Input/Output Signal เข้ากับ Operation หรืออุปกรณ์ที่ต้องการควบคุม

2. ตัวอย่าง Logic: ประตูนิรภัยเปิดเมื่อหุ่นยนต์หยุดสนิท

// แนวคิด Signal wiring ใน Logic Block
Robot.AtHomePosition == true  AND  CycleComplete == true
    --> SafetyDoor.Open = true

ตัวอย่างการใช้ .NET API (C#) ของ Process Simulate เพื่อไล่อ่านรายการ Operation ทั้งหมดใน Study แบบอัตโนมัติ:

using Tecnomatix.Engineering;

public class ListOperations
{
    public static void Run()
    {
        PmStudy study = PS.Study;
        foreach (PmOperation op in study.GetAllOperations())
        {
            Console.WriteLine("Operation: " + op.Name + " | Time: " + op.Time);
        }
    }
}

3. ตัวอย่าง .NET API: สลับ Resource อัตโนมัติแล้วเช็คการชนซ้ำ

ใช้แทนการปรับ Layout ด้วยมือทีละแบบ เมื่อต้องการเทียบหลาย Scenario เช่น ตำแหน่งหุ่นยนต์หลายจุด

using Tecnomatix.Engineering;

public class CollisionSweep
{
    public static void Run()
    {
        double[] robotOffsets = { 0, 50, 100 };
        foreach (double offset in robotOffsets)
        {
            // ปรับตำแหน่ง Robot Resource แล้วรัน Collision Detection
            PS.CollisionDetection.RunOnce();
            Console.WriteLine("Offset " + offset + " -> collisions: "
                + PS.CollisionDetection.CollisionCount);
        }
    }
}

4. Offline Programming (OLP)

เมื่อ Pose และลำดับ Operation ผ่านการตรวจสอบในซอฟต์แวร์แล้ว ใช้ฟีเจอร์ OLP (Offline Programming) แปลง Pose/Path ที่ Teach ไว้เป็นโปรแกรมควบคุมในภาษาเฉพาะของยี่ห้อหุ่นยนต์ เช่น RAPID (ABB), KRL (KUKA), TP (FANUC) แล้วส่งไฟล์นั้นไปโหลดใช้กับหุ่นยนต์จริงได้ทันที ลดเวลา Teach หน้างาน

  1. ตรวจสอบว่า Operation และ Pose ทั้งหมดผ่าน Reachability และ Collision Check แล้ว
  2. เปิดเมนู Robotics → OLP → Generate Program
  3. เลือก Robot Controller/ยี่ห้อที่ตรงกับหุ่นยนต์จริง
  4. Export ไฟล์โปรแกรมออกมา แล้วโหลดเข้า Controller ของหุ่นยนต์จริง

5. Resource Library และการนำกลับมาใช้ซ้ำ

เก็บ Robot, Gripper, Fixture มาตรฐานไว้ใน Resource Library กลาง แล้วดึงมาใช้ข้าม Study/โปรเจกต์ได้ โดยไม่ต้องสร้างใหม่ทุกครั้ง ช่วยให้ทีมงานหลายคนใช้ทรัพยากรชุดเดียวกันสอดคล้องกัน

Tip: ตั้งชื่อ Operation และ Signal ให้สื่อความหมายเสมอ (เช่น Pick_PartA_Station1) เพราะเมื่อ Study มี Operation หลายร้อยตัว การไล่ดูใน PERT chart จะยากมากถ้าตั้งชื่อไม่สื่อความหมาย
