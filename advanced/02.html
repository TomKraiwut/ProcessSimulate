โครงสร้างพื้นฐานของ .NET API

Process Simulate เปิด .NET API ผ่าน namespace Tecnomatix.Engineering ให้เขียนสคริปต์ C# ควบคุม Study ได้โดยตรง แทนการคลิกทำเองในโปรแกรมทีละขั้นตอน เหมาะกับงานที่ต้องทำซ้ำจำนวนมาก เช่น ไล่อ่าน Operation หลายร้อยตัว

ตัวอย่างสคริปต์ไล่อ่านรายการ Operation ทั้งหมดใน Study แบบอัตโนมัติ:

using Tecnomatix.Engineering;

public class ListOperations
{
    public static void Run()
    {
        PmStudy study = PS.Study;
        foreach (PmOperation op in study.GetAllOperations())
        {
            Console.WriteLine("Operation: " + op.Name + " | Time: " + op.Time);
        }
    }
}
ข้อควรระวัง: ก่อนรันสคริปต์ตรวจสอบว่ามี Study เปิดอยู่จริง (PS.Study ไม่เป็น null) ไม่งั้นสคริปต์จะ error ทันทีตั้งแต่บรรทัดแรก
คำถามฝึกคิด: ถ้าต้องการนับจำนวน Operation ทั้งหมดที่ Time มากกว่า 5 วินาที จะปรับสคริปต์ตัวอย่างข้างบนอย่างไร?
เฉลย: เพิ่มตัวแปรนับและเงื่อนไข if (op.Time > 5) ภายในลูป foreach แล้ว เพิ่มค่าตัวแปรนับทีละ 1 เมื่อเงื่อนไขเป็นจริง จากนั้นพิมพ์ผลรวมหลังจบลูป
