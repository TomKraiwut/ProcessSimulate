3. .NET API ขั้นสูง: ไล่อ่าน Study อัตโนมัติ

วัตถุประสงค์การเรียนรู้

  1. เขียนสคริปต์สลับ Resource หลาย Scenario แล้วตรวจสอบการชนซ้ำอัตโนมัติได้
  2. ประเมินได้ว่าเมื่อไหร่ควรใช้สคริปต์แทนการปรับ Layout ด้วยมือ

สลับ Resource อัตโนมัติแล้วเช็คการชนซ้ำ

ใช้แทนการปรับ Layout ด้วยมือทีละแบบ เมื่อต้องการเทียบหลาย Scenario เช่น ตำแหน่งหุ่นยนต์หลายจุด

using Tecnomatix.Engineering;

public class CollisionSweep
{
    public static void Run()
    {
        double[] robotOffsets = { 0, 50, 100 };
        foreach (double offset in robotOffsets)
        {
            // ปรับตำแหน่ง Robot Resource แล้วรัน Collision Detection
            PS.CollisionDetection.RunOnce();
            Console.WriteLine("Offset " + offset + " -> collisions: "
                + PS.CollisionDetection.CollisionCount);
        }
    }
}
Tip: เก็บผลลัพธ์แต่ละ Scenario ลง List หรือเขียนออกไฟล์ CSV แทนการพิมพ์ผลลัพธ์ทาง Console อย่างเดียว จะช่วยให้เปรียบเทียบหลาย Scenario ย้อนหลังได้ง่ายกว่า โดยเฉพาะเมื่อสลับหลายสิบค่า
คำถามฝึกคิด: เมื่อไหร่ควรเขียนสคริปต์แบบนี้ แทนการปรับตำแหน่งด้วยมือใน Graphics Viewer?
เฉลย: เมื่อต้องเทียบหลาย Scenario ที่มีรูปแบบชัดเจน (เช่น สลับตำแหน่งเป็นช่วงๆ) และต้องทำซ้ำบ่อย — สคริปต์ทำให้ผลลัพธ์แม่นยำสม่ำเสมอและประหยัดเวลากว่าการคลิกปรับเองทีละ Scenario มาก
