Basic: เริ่มต้นใช้งาน Process Simulate

พื้นฐานที่ต้องรู้ก่อนสร้างเซลล์การผลิตจำลองแรกของคุณ

1. หน้าตาโปรแกรม (User Interface)

เมื่อเปิดโปรแกรมและสร้าง Study ใหม่ จะเจอส่วนหลักๆ ดังนี้

ส่วนประกอบหน้าที่
Object Tree / Study Treeโครงสร้างของ Study ทั้งหมด แบ่งเป็น Resources, Operations, Parts
Graphics Viewerพื้นที่แสดงโมเดล 3 มิติของเซลล์การผลิต ใช้เลือกและจัดวาง Resource/Part
Operation Tree / Sequence Editorแสดงลำดับ Operation แบบ PERT chart หรือ Gantt เพื่อกำหนดว่าอะไรทำงานก่อน-หลัง
Jog/Teach Panelแผงควบคุมขยับหุ่นยนต์ทีละแกน (Jog) และบันทึกท่าทาง (Pose/Teach)

2. Object พื้นฐานที่ใช้บ่อย

Objectใช้ทำอะไร
Studyไฟล์งานหลักที่รวม Resource, Operation, Part ของสถานการณ์จำลองหนึ่งชุด
Resourceทรัพยากรจริงในเซลล์ เช่น Robot, Fixture, Tool/Gripper, Device (สายพาน, ประตูนิรภัย)
Partชิ้นงานที่ถูกหยิบจับหรือแปรรูปในกระบวนการ
Operationขั้นตอนงานหนึ่งอย่าง เช่น Pick, Place, Weld Point, Robot Move
PERT Chartแผนภาพแสดงลำดับก่อน-หลังของ Operation ทั้งหมดใน Study
Poseท่าทาง (มุมข้อต่อ) ของหุ่นยนต์ ณ จุดใดจุดหนึ่ง บันทึกด้วยการ Teach

3. สร้างงานแรก: หยิบ-วางชิ้นงานด้วยหุ่นยนต์ (Pick and Place)

ทำตามขั้นตอนนี้เพื่อสร้างงานหยิบชิ้นงานจากจุด A ไปวางที่จุด B

  1. สร้าง Study ใหม่ แล้ว Import หุ่นยนต์ (Robot Resource) และชิ้นงาน (Part) เข้ามาในเซลล์
  2. จัดวางตำแหน่งหุ่นยนต์ ชิ้นงานต้นทาง และปลายทางในพื้นที่ทำงาน
  3. สร้าง Operation → Pick แล้วใช้ Jog/Teach เลื่อนหุ่นยนต์ไปยังตำแหน่งหยิบ บันทึกเป็น Pose
  4. สร้าง Operation → Place ทำแบบเดียวกันที่ตำแหน่งวาง
  5. เปิด PERT chart เรียงลำดับ Pick ก่อน Place
  6. กด Play ใน Sequence Editor / Simulation Player เพื่อรันและตรวจสอบการชน (Collision Check)
Tip: ก่อนรัน ให้ผูก Part เข้ากับปลายแขนหุ่นยนต์ด้วยคำสั่ง Attach ใน Operation Pick — ถ้าลืม ชิ้นงานจะไม่เคลื่อนที่ตามหุ่นยนต์เวลารัน แม้ Pose จะถูกต้องแล้วก็ตาม

4. ดูผลลัพธ์เบื้องต้น

หลังรันจบ ตรวจสอบผลได้จาก:

  • Collision Report — รายการจุดที่ชนกันระหว่างหุ่นยนต์กับสิ่งแวดล้อม
  • Cycle Time — เวลารวมของ Operation ทั้งหมดใน Study
  • Reach/Reachability — ตรวจว่าหุ่นยนต์เอื้อมถึงทุกตำแหน่ง Pose ได้จริงหรือไม่
ข้อควรระวัง: อย่าลืมกด Reset ก่อนรันใหม่ทุกครั้ง ไม่งั้น Pose และสถานะการ Attach/Detach จะค้างจากรอบก่อนหน้า ทำให้ผลจำลองคลาดเคลื่อน
