Process Simulate Tutorial

2. หน้าตาโปรแกรม

วัตถุประสงค์การเรียนรู้

  1. จำตำแหน่งและหน้าที่ของส่วนประกอบหลักในโปรแกรมได้
  2. เปิดโปรแกรม สร้าง Study ใหม่ และรู้จักหน้าจอหลักได้ด้วยตัวเอง

ส่วนประกอบหลักของโปรแกรม

เมื่อเปิดโปรแกรมและสร้าง Study ใหม่ จะเจอส่วนหลักๆ ดังนี้

ส่วนประกอบหน้าที่
Object Tree / Study Treeโครงสร้างของ Study ทั้งหมด แบ่งเป็น Resources, Operations, Parts
Graphic Viewerพื้นที่แสดงโมเดล 3 มิติของเซลล์การผลิต มี Graphic Viewer Toolbar และ Object Toolbars ลอยอยู่ในหน้าจอเดียวกัน
Navigation Cubeลูกบาศก์มุมจอสำหรับหมุนมุมมอง (Rotate) และเดินดูรอบวัตถุ (Walk around object) แบบเร็วๆ
Operation Tree / Sequence Editorแสดงลำดับ Operation แบบ PERT chart หรือ Gantt เพื่อกำหนดว่าอะไรทำงานก่อน-หลัง
Jog/Teach Panelแผงควบคุมขยับหุ่นยนต์ทีละแกน (Jog) และบันทึกท่าทาง (Pose/Teach)
Attribute Windowเปิดจากดับเบิลคลิก Object — ตั้งค่าคุณสมบัติเฉพาะของ Object นั้น
Tip: คลิกขวาที่ Object เกือบทุกจุดในโปรแกรม (Object Tree, Graphic Viewer, Operation Tree) จะเจอ context menu ที่รวมคำสั่งที่ใช้บ่อยที่สุดของ Object นั้นไว้ให้แล้ว เร็วกว่าไล่หาในเมนูบนสุดมาก

สร้าง Study ใหม่

  1. 1เปิดโปรแกรม Process Simulate แล้วเลือก Create New Study
  2. 2เลือกโฟลเดอร์ Library ของโปรเจกต์ (เช่น My_Project/Library) และตั้งชื่อ Study
  3. 3สังเกตหน้าจอเปล่า — Object Tree ด้านซ้าย, Graphic Viewer ตรงกลางพร้อม Navigation Cube มุมจอ
  4. 4ลองเปิด Operation Tree จากเมนู View เพื่อดูตำแหน่งของมัน
Tip: จัด Layout หน้าต่าง (Graphic Viewer, Object Tree, Operation Tree) ให้เห็นพร้อมกันตั้งแต่แรก จะช่วยให้ไล่ดูว่ากำลังแก้ Object ไหนอยู่ได้ง่ายขึ้นมาก โดยเฉพาะเมื่อ Study เริ่มมี Operation หลายสิบตัว
คำถามฝึกคิด: ถ้าจัดวาง Resource ผิดตำแหน่งใน Graphic Viewer จะแก้ไขตำแหน่งได้จากส่วนไหนของโปรแกรม โดยไม่ต้องลบแล้วสร้างใหม่?
เฉลย: เลือก Resource ใน Object Tree หรือคลิกใน 3D Viewer แล้วแก้ค่าตำแหน่ง (Location) ได้จาก Attribute Window หรือใช้ Manipulator ลากในหน้าจอ 3D โดยตรง
