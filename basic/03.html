  1. จำ Object พื้นฐาน 6 ตัวที่ใช้บ่อยที่สุด และหน้าที่ของแต่ละตัวได้

Object พื้นฐาน 6 ตัวที่ใช้บ่อย

Object หลักในการสร้างเซลล์อ้างอิงจากแนวคิด Bill of Process (BOP) ที่แนะนำไว้ในบทที่แล้ว บวกกับ 2 Object เฉพาะของ Process Simulate ที่ใช้ควบคุมการเคลื่อนที่และลำดับงาน:

Objectใช้ทำอะไร
Studyไฟล์งานหลักที่รวม Resource, Operation, Part ของสถานการณ์จำลองหนึ่งชุด
Resourceทรัพยากรจริงในเซลล์ (BOP: Resource) เช่น Robot, Fixture, Tool/Gripper, Device (สายพาน, ประตูนิรภัย)
Partชิ้นงานที่ถูกหยิบจับหรือแปรรูปในกระบวนการ (BOP: Part)
Operationขั้นตอนงานหนึ่งอย่าง (BOP: Operation) แบ่งเป็น Device Operation กับ Robot Operation เช่น Pick, Place, Weld Point
PERT Chartแผนภาพแสดงลำดับก่อน-หลังของ Operation ทั้งหมดใน Study
Poseท่าทาง (มุมข้อต่อ) ของหุ่นยนต์ ณ จุดใดจุดหนึ่ง บันทึกด้วยการ Teach
ข้อควรระวัง: Object แต่ละตัวมี Attribute เฉพาะของตัวเอง เช่น Robot มี Reach/Payload, Operation มี Time — ก่อนเริ่มสร้างงานจริง ควรเปิด Attribute Window ของแต่ละ Object ดูก่อนว่ามีค่าอะไรให้ตั้งบ้าง จะช่วยลดเวลาย้อนกลับมาแก้ทีหลัง

ความสัมพันธ์ระหว่าง Object

Study หนึ่งไฟล์ประกอบด้วย Resource และ Part หลายตัว โดย Operation คือสิ่งที่ผูก Resource เข้ากับ Part (เช่น Robot หยิบ Part ด้วย Operation Pick) แล้ว PERT chart คือสิ่งที่เรียงลำดับว่า Operation ไหนเกิดก่อน-หลัง ส่วน Pose คือรายละเอียดภายใน Operation ว่าหุ่นยนต์ต้องอยู่ท่าไหนในแต่ละจุด — ถ้ามี Part หลายชิ้นที่ต้องประกอบสัมพันธ์กัน (เช่น จุดเชื่อมที่ยึดสอง Part เข้าด้วยกัน) ความสัมพันธ์นั้นถูกเก็บเป็น Manufacturing Feature ตาม BOP

คำถามฝึกคิด: ถ้าต้องการให้หุ่นยนต์ตัวเดียวหยิบชิ้นงาน 2 แบบสลับกัน ต้องสร้าง Part กี่ตัว และ Operation กี่ตัว?
เฉลย: สร้าง Part 2 ตัว (แทนชิ้นงานแต่ละแบบ) และสร้าง Operation Pick แยกสำหรับแต่ละ Part เพราะแต่ละ Part มักอยู่คนละตำแหน่งและต้องการ Pose หยิบที่ต่างกัน แม้ใช้ Robot และ Gripper ตัวเดียวกันก็ตาม
