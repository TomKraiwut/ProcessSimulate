4. สร้างงานแรก: Pick and Place

วัตถุประสงค์การเรียนรู้

  1. สร้างงานหยิบ-วางชิ้นงานด้วยหุ่นยนต์ (Pick and Place) ได้ด้วยตัวเอง
  2. ใช้ Jog/Teach บันทึก Pose และเรียงลำดับด้วย PERT chart ได้

สร้างงานแรก: หยิบ-วางชิ้นงานด้วยหุ่นยนต์ (Pick and Place)

ทำตามขั้นตอนนี้เพื่อสร้างงานหยิบชิ้นงานจากจุด A ไปวางที่จุด B

  1. 1สร้าง Study ใหม่ แล้ว Import หุ่นยนต์ (Robot Resource) และชิ้นงาน (Part) เข้ามาในเซลล์
  2. 2จัดวางตำแหน่งหุ่นยนต์ ชิ้นงานต้นทาง และปลายทางในพื้นที่ทำงาน
  3. 3สร้าง Operation → Pick แล้วใช้ Jog/Teach เลื่อนหุ่นยนต์ไปยังตำแหน่งหยิบ บันทึกเป็น Pose
  4. 4สร้าง Operation → Place ทำแบบเดียวกันที่ตำแหน่งวาง
  5. 5เปิด PERT chart เรียงลำดับ Pick ก่อน Place
  6. 6กด Play ใน Sequence Editor / Simulation Player เพื่อรันและตรวจสอบการชน (Collision Check)
Tip: ก่อนรัน ให้ผูก Part เข้ากับปลายแขนหุ่นยนต์ด้วยคำสั่ง Attach ใน Operation Pick — ถ้าลืม ชิ้นงานจะไม่เคลื่อนที่ตามหุ่นยนต์เวลารัน แม้ Pose จะถูกต้องแล้วก็ตาม

ตัวอย่าง: กระบวนการหยิบ-ป้อนชิ้นงานเข้าเครื่อง CNC

ตัวอย่างคลาสสิกของงาน Pick and Place ในสายการผลิตจริงคือกระบวนการหยิบชิ้นงานป้อนเครื่อง CNC ซึ่งประกอบด้วยหลาย Operation ต่อเนื่องกัน: Part Bank Flow In → Robot Load In → Machine Door Close → CNC Machining → Machine Door Open → Robot Load Out — สังเกตว่ามีทั้ง Robot Operation (หุ่นยนต์หยิบ-วาง) และ Device Operation (ประตูเครื่องเปิด-ปิด, การ Machining ของ CNC) ผสมกัน ตามแนวคิด BOP ที่เรียนในบทที่แล้ว

ตำแหน่งหยิบ-วางแต่ละจุดถูกเก็บเป็น Location ซึ่งสร้าง/แก้ไขได้ผ่านคำสั่ง Manipulate Location และ Add Location โดยไม่ต้องลบ Operation เดิมทิ้งเมื่อจุดคลาดเคลื่อนเล็กน้อย

รู้ไว้: งานหยิบ-วางแบบเรียงซ้อนชิ้นงานเป็นชั้นๆ (เช่น วางลงพาเลท) มีเทมเพลตสำเร็จรูปเรียกว่า Cobot Palletizer ช่วยลดเวลาสร้าง Operation ซ้ำๆ เมื่อรูปแบบการวางเป็นตาราง/เรียงแถวที่คาดเดาได้
คำถามฝึกคิด: ถ้าตำแหน่งวาง (Place) อยู่นอกระยะที่หุ่นยนต์เอื้อมถึง จะรู้ได้จากที่ไหนก่อนที่จะรันแล้วเจอปัญหา?
เฉลย: ใช้ฟีเจอร์ Reach Test/Reachability ตรวจสอบก่อน Teach จริง — ถ้าจุดนั้นอยู่นอกระยะ โปรแกรมจะแจ้งเตือน ทำให้ปรับตำแหน่งหุ่นยนต์หรือ Fixture ก่อนเสียเวลา Teach ทีละจุด (ดูรายละเอียดใน Basic บทที่ 5)
