Process Simulate Tutorial

1. อุตสาหกรรมยานยนต์ (Body-in-White Welding)

วัตถุประสงค์การเรียนรู้

  1. เห็นตัวอย่างการประยุกต์ใช้ Process Simulate ในเซลล์เชื่อมตัวถังรถยนต์จริง
  2. เชื่อมโยงความรู้จากหลายบทเข้าด้วยกันเป็นเซลล์เดียว

บริบทอุตสาหกรรม

อุตสาหกรรมยานยนต์ใช้ Process Simulate ออกแบบเซลล์เชื่อมตัวถังรถ (Body-in-White) ซึ่งมักมีหุ่นยนต์หลายตัวเชื่อมจุดจำนวนมาก (หลักร้อยถึงหลักพันจุดต่อคัน) ในพื้นที่จำกัด ต้องวางแผน Cycle Time ให้ทันตามเป้าการผลิตต่อวัน

โจทย์ตัวอย่าง

ออกแบบเซลล์เชื่อม 2 สถานีให้รองรับตัวถังรถ 1 คัน โดยมี Robot 4 ตัว (2 ตัวต่อสถานี) เชื่อมจุด Spot Weld รวม 120 จุด ภายใน Cycle Time เป้าหมายไม่เกิน 90 วินาทีต่อคัน

โครงสร้างโมเดล

  • Fixture ยึดตัวถังรถให้นิ่งตลอดกระบวนการเชื่อม (Intermediate บทที่ 1)
  • Robot แต่ละตัว Mount ปืนเชื่อมและตั้งค่า ExtTcp ให้ตรงกับปลายปืนจริง (Intermediate บทที่ 2)
  • สร้าง Weld Point Operation ครบทุกจุด จัดกลุ่มตามตำแหน่งเพื่อลดระยะทางเคลื่อนที่ (Intermediate บทที่ 3)
  • จัดลำดับใน PERT chart ให้ Robot 2 ตัวในสถานีเดียวกันเชื่อมพร้อมกันแบบ Parallel เมื่อไม่ชนกัน (Intermediate บทที่ 4)
  • ตรวจสอบ Collision Set ระหว่าง Robot คู่ที่ทำงานใกล้กัน (Intermediate บทที่ 5)
คำถามฝึกคิด: ถ้าตรวจสอบแล้วพบว่า Cycle Time เกินเป้า 90 วินาทีไปมาก แม้จัด Parallel Operation ทุกจุดที่ทำได้แล้ว ควรพิจารณาทางเลือกอะไรต่อ?
เฉลย: พิจารณาเพิ่มจำนวนหุ่นยนต์ต่อสถานี หรือแบ่งจุดเชื่อมออกเป็นสถานีเพิ่มเติม (เพิ่ม Station ขนาน) แทนการพยายามบีบทุกจุดเชื่อมไว้ในสถานีเดิม — ต้องชั่งน้ำหนักกับต้นทุนอุปกรณ์เพิ่มเทียบกับ Throughput ที่ต้องการ
