Process Simulate Tutorial

3. งานพ่นสี (Paint Shop Simulation)

วัตถุประสงค์การเรียนรู้

  1. เห็นตัวอย่างการจำลองงานพ่นสีที่ต้องการความสม่ำเสมอของ Path
  2. เข้าใจว่าทำไมงานพ่นสีให้ความสำคัญกับความเร็วและระยะห่างของปืนพ่นคงที่

บริบทอุตสาหกรรม

งาน Robotics Painting ไม่ได้ตรวจแค่ภาพเคลื่อนไหว (Visual Simulation) แต่ต้องประเมิน ความหนาของสีจริง ด้วย เพราะระยะและความเร็วปืนพ่นที่ไม่คงที่ทำให้สีหนา-บางไม่เท่ากันบนชิ้นงานเดียวกัน — Process Simulate มี Paint Workflow เฉพาะทาง 4 ขั้นตอน: Create Path → OLP → Prepare Surface → Paint Simulation

โจทย์ตัวอย่าง

ออกแบบเซลล์พ่นสีตัวถังชิ้นส่วนพลาสติก โดยหัวพ่น (Paint Gun) ต้องรักษาระยะห่างจากผิวชิ้นงานคงที่ตลอดเส้นทาง และความเร็วเคลื่อนที่สม่ำเสมอ เพื่อให้ความหนาสีเท่ากันทั้งชิ้น

โครงสร้างโมเดล

  • Tool หัวพ่นสี (Paint Gun) Mount กับ Robot และตั้งค่า ExtTcp ให้ตรงกับปลายหัวพ่นจริง (Intermediate บทที่ 2)
  • ใช้ Continuous Process Generator สร้าง Coverage Pattern อัตโนมัติจากการเลือกพื้นผิว (Face Selection) แทนการ Teach จุดพ่นทีละจุด
  • ใส่ Via Point ตามความโค้งของผิวชิ้นงานเพื่อรักษาระยะห่างคงที่ (Intermediate บทที่ 2)
  • รัน Paint Coverage Algorithm — นับจำนวนครั้งที่แต่ละจุดบนผิวถูก Paint Fan พ่นผ่าน (ต้องมี Collision/Penetration ระหว่าง Fan กับผิวจึงนับ)
  • รัน Paint Thickness Algorithm — คำนวณความหนาสี (หน่วยไมครอน) จาก Paint Graph ต่อ Brush ที่ระยะห่างและความเร็ว TCPF ที่กำหนด
คำถามฝึกคิด: ทำไมงานพ่นสีถึงต้องใส่ Via Point ถี่กว่างานเชื่อมจุดทั่วไปมาก?
เฉลย: ผิวชิ้นงานพ่นสีส่วนใหญ่มีความโค้งต่อเนื่อง หาก Via Point ห่างเกินไป หุ่นยนต์จะเคลื่อนที่เป็นเส้นตรง ระหว่างจุด ทำให้ระยะห่างจากผิวชิ้นงานไม่คงที่ (ใกล้ตรงกลางแคบลง ห่างตรงจุดที่ Via Point อยู่) ส่งผลให้สีหนา-บางไม่เท่ากัน
