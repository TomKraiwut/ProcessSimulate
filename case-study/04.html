Process Simulate Tutorial

4. อิเล็กทรอนิกส์ (Precision Pick and Place)

วัตถุประสงค์การเรียนรู้

  1. เห็นตัวอย่างการจำลองงานประกอบอิเล็กทรอนิกส์ที่ต้องการความแม่นยำสูง
  2. เข้าใจการนำ Collision Set และ Reachability มาใช้ร่วมกันในโจทย์ที่พื้นที่ทำงานแคบ

บริบทอุตสาหกรรม

งานประกอบอิเล็กทรอนิกส์ต้องการความแม่นยำระดับมิลลิเมตรหรือต่ำกว่า และมักทำงานในพื้นที่แคบที่มีอุปกรณ์วางชิดกันมาก ทำให้ความเสี่ยงชนสูงกว่างานอุตสาหกรรมหนักทั่วไป

โจทย์ตัวอย่าง

ออกแบบเซลล์หยิบวางชิ้นส่วนอิเล็กทรอนิกส์ขนาดเล็กลงบนแผงวงจร โดยพื้นที่วางอุปกรณ์รอบข้างเหลือระยะห่างจากแขนหุ่นยนต์ ไม่ถึง 5 ซม. ในบางจุด

โครงสร้างโมเดล

  • Fixture ยึดแผงวงจรให้นิ่งสนิทระหว่างวางชิ้นส่วน (Intermediate บทที่ 1)
  • Gripper ขนาดเล็กแม่นยำสูง Mount กับ Robot และตั้งค่า ExtTcp ละเอียด (Intermediate บทที่ 2)
  • สร้าง Collision Set เฉพาะคู่ Robot กับอุปกรณ์รอบข้างที่อยู่ใกล้ที่สุด แทนการเช็คทุก Object ในเซลล์ (Intermediate บทที่ 5)
  • ตรวจสอบ Reachability ทุกตำแหน่งวางชิ้นส่วนบนแผงวงจรก่อน Teach จริง (Basic บทที่ 5)
  • ใส่ Approach/Departure สั้นๆ ทุกจุดวาง เพื่อลดโอกาสแขนหุ่นยนต์กวาดผ่านอุปกรณ์ข้างเคียง (Intermediate บทที่ 2)
คำถามฝึกคิด: ทำไมเซลล์งานอิเล็กทรอนิกส์แบบนี้ถึงควรตั้ง Collision Set เฉพาะคู่ที่เสี่ยงจริง แทนที่จะเช็คทุก Object ในเซลล์แบบละเอียดที่สุดเพื่อความปลอดภัยสูงสุด?
เฉลย: พื้นที่แคบทำให้ Object อยู่ใกล้กันตามธรรมชาติอยู่แล้ว การเช็คทุกคู่แบบละเอียดจะทำให้ Collision Report เต็มไปด้วยรายการที่ไม่เกี่ยวข้อง (เช่น ฐานยึด Fixture ที่อยู่ใกล้กันแต่ไม่มีทางชน) จนหารายการที่เป็นความเสี่ยงจริงยากขึ้น
