Example File: ตัวอย่างเซลล์การผลิตจริง

ฝึกทำตามตัวอย่างเหล่านี้เพื่อความเข้าใจที่ลึกขึ้น ไฟล์ Study จริงของ Process Simulate ใช้นามสกุล .psz สามารถอัปโหลดเพิ่มในโฟลเดอร์ /examples ของ repo นี้ได้

วิธีเพิ่มไฟล์ตัวอย่างจริง: สร้างโฟลเดอร์ examples/ แล้ววางไฟล์ .psz ของคุณลงไป จากนั้นใส่ลิงก์ดาวน์โหลดในหน้านี้ เช่น <a href="examples/cell-01.psz">ดาวน์โหลด</a>

ตัวอย่างที่ 1: เซลล์หยิบ-วางเดี่ยว (Single Robot Pick and Place)

โครงสร้าง: Robot → Operation(Pick) → Operation(Place)

  • Robot: 6-axis, ติดตั้ง Gripper แบบ 2 นิ้ว
  • Part: ชิ้นงานที่จุดหยิบ 1 ตำแหน่ง จุดวาง 1 ตำแหน่ง
  • Cycle Time เป้าหมาย: ไม่เกิน 8 วินาทีต่อรอบ

คำถามฝึกคิด: รันแล้วชิ้นงานไม่เคลื่อนที่ตามหุ่นยนต์ตอน Place ทั้งที่ Pose ถูกต้อง เกิดจากอะไร?

เฉลย: ลืมสั่ง Attach ชิ้นงานเข้ากับปลายแขนหุ่นยนต์ใน Operation Pick — ต้อง Attach ตอนหยิบ และ Detach ตอนวาง ไม่งั้นชิ้นงานจะค้างอยู่ตำแหน่งเดิมตลอดการจำลอง

ตัวอย่างที่ 2: สองหุ่นยนต์ทำงานร่วมกันในเซลล์เดียว (Dual Robot Cell)

โครงสร้าง: Robot1 (Weld) + Robot2 (Handling) ทำงานพร้อมกันในพื้นที่ที่มีจุดตัด (Shared Zone)

ใช้ Logic Block ผูก Signal กันชนกัน (Interlock) ระหว่างสองหุ่นยนต์

// แนวคิด Interlock Logic
Robot1.InZoneA == true  --> Robot2.HoldAtWaitPoint = true
Robot1.InZoneA == false --> Robot2.HoldAtWaitPoint = false

คำถามฝึกคิด: ถ้าไม่ใส่ Interlock จะเกิดอะไรขึ้นเมื่อทั้งสองหุ่นยนต์เข้าพื้นที่ Shared Zone พร้อมกัน?

เฉลย: Collision Detection จะรายงานการชนกันของแขนหุ่นยนต์ทั้งสองตัวใน Shared Zone — ในเซลล์จริงคือความเสียหายของอุปกรณ์ จึงต้องมี Interlock ทุกครั้งที่มีพื้นที่ทำงานร่วมกัน

ตัวอย่างที่ 3: จุดเชื่อม Weld Point และการลด Cycle Time

Study ที่มี Weld Point Operation 20 จุด เรียงลำดับใน PERT chart แบบเส้นตรง (Sequential)

คำถามฝึกคิด: จะลด Cycle Time รวมของ Study นี้โดยไม่ลดจำนวนจุดเชื่อมได้อย่างไร?

เฉลย: จัดกลุ่มจุดเชื่อมที่อยู่ใกล้กันให้ Robot เคลื่อนที่เป็นเส้นทางสั้นที่สุด (Path Optimization) และพิจารณาใช้ 2 หุ่นยนต์เชื่อมคนละฝั่งพร้อมกัน (Parallel Operation ใน PERT chart) แทนการเรียงจุดแบบ Sequential ทั้งหมด
