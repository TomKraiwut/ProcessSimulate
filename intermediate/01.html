Process Simulate Tutorial

1. Resource ขั้นกลาง

วัตถุประสงค์การเรียนรู้

  1. แยกความแตกต่างของ Device, Fixture, Gripper/Tool และ Conveyor ได้
  2. เลือกใช้ Resource ที่เหมาะกับสถานการณ์ในเซลล์จริงได้

Resource ขั้นกลางที่ใช้บ่อย

Resourceใช้ทำอะไร
Deviceอุปกรณ์ที่มีการเคลื่อนไหวหรือสถานะเปลี่ยนได้ เช่น สายพาน, ประตูนิรภัย, แขนดัน
Fixtureอุปกรณ์ยึดจับชิ้นงานให้อยู่กับที่ระหว่างกระบวนการ
Gripper / Toolอุปกรณ์ปลายแขนหุ่นยนต์ ใช้หยิบจับหรือทำงาน (เช่น ปืนเชื่อม, หัวพ่นสี)
Conveyorสายพานลำเลียงชิ้นงานระหว่างสถานี มักผูกกับ Device เพื่อจำลองการเคลื่อนที่
ข้อควรระวัง: Gripper/Tool ต้องผูกเข้ากับ Robot ก่อนใช้งาน (Mount) ไม่งั้นหุ่นยนต์จะไม่มี Tool Center Point (TCP) ที่ถูกต้องสำหรับคำนวณตำแหน่ง Pose

สร้าง Resource ประเภท Device และดึงจาก Asset Library

Resource ประเภท Device (เช่น สายพาน, ประตูนิรภัย, แขนดัน) สร้างได้เองจากโมเดล 3 มิติที่นำเข้ามา หรือดึงจาก Asset Library ซึ่งมี Component สำเร็จรูปให้ดาวน์โหลดพร้อมใช้ (Download Asset and Robot) ทั้งหุ่นยนต์และอุปกรณ์มาตรฐาน แทนการสร้าง Kinematics เองทั้งหมดตั้งแต่ต้น ช่วยประหยัดเวลาได้มากสำหรับ Resource ที่ไม่ต้องปรับแต่งพิเศษ

เลือกใช้ Resource ให้เหมาะกับสถานการณ์

หลักคร่าวๆ: ถ้าชิ้นงานต้อง "อยู่นิ่ง" ระหว่างทำงาน ใช้ Fixture, ถ้าต้อง "เคลื่อนที่ต่อเนื่อง" ใช้ Conveyor/Device, ถ้าเป็นสิ่งที่หุ่นยนต์ "ถืออยู่ที่ปลายแขน" ใช้ Gripper/Tool

คำถามฝึกคิด: เซลล์เชื่อมชิ้นงานที่ต้องยึดชิ้นงาน 2 ชิ้นให้นิ่งขณะหุ่นยนต์เชื่อม แล้วปล่อยสายพานพาไปสถานีถัดไป ต้องใช้ Resource ประเภทไหนบ้าง?
เฉลย: ใช้ Fixture ยึดชิ้นงานระหว่างเชื่อม, Tool (ปืนเชื่อม) ติดที่ปลายแขน Robot, และ Conveyor/Device ลำเลียงชิ้นงานหลังเชื่อมเสร็จไปสถานีถัดไป
