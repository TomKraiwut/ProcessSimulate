2. Path และ Location ขั้นสูง

วัตถุประสงค์การเรียนรู้

  1. เข้าใจว่า ExtTcp/Tool Center Point คืออะไร และทำไมต้องกำหนดให้ถูก
  2. ใช้ Approach/Departure และ Via Point ควบคุมเส้นทางหุ่นยนต์ให้ปลอดภัยขึ้นได้

Robot Frame: Base Frame และ Tool Center Point Frame

ตำแหน่งของหุ่นยนต์อ้างอิงจากสอง Frame หลักเสมอ: Base Frame (จุดฐานของหุ่นยนต์ที่ยึดกับพื้น/โครงสร้าง) และ Tool Center Point Frame (TCPF) — จุดอ้างอิงที่ปลาย Gripper/Tool ไม่ใช่ปลายแขนหุ่นยนต์เอง ทุกครั้งที่หุ่นยนต์เคลื่อนที่ไปยัง Pose หนึ่ง โปรแกรมคำนวณตำแหน่งจาก TCPF เทียบกับ Base Frame หากติดตั้ง Tool ยาวขึ้นหรือเปลี่ยน Tool ต้องปรับ ExtTcp (External TCP) ให้ตรงกับ Tool ตัวใหม่เสมอ ไม่งั้นตำแหน่งที่ Teach ไว้จะคลาดเคลื่อนทั้งหมด

Motion Type และ Path Editor

การเคลื่อนที่ระหว่าง Pose แต่ละแบบให้ผลต่างกัน ตั้งค่าได้ผ่าน Path Editor:

Motion Typeลักษณะการเคลื่อนที่
Jointแต่ละแกนหมุนไปพร้อมกันจนถึงเป้าหมาย เส้นทางไม่แน่นอนแต่เร็วที่สุด
LinearTCP เคลื่อนที่เป็นเส้นตรงระหว่างสองจุด ควบคุมเส้นทางได้แน่นอน เหมาะกับงานที่ต้องเลี่ยงสิ่งกีดขวาง
CircleTCP เคลื่อนที่เป็นส่วนโค้งผ่าน 3 จุดที่กำหนด ใช้กับงานที่ต้องการเส้นทางโค้งแม่นยำ

Frame of Reference เมื่อจัดวางตำแหน่ง

เวลาใช้ Placement Manipulator ลากจัดตำแหน่ง Object จะอ้างอิงจุดหมุนได้หลายแบบ: Geometric Center (จุดกึ่งกลางรูปทรงของ Object เอง), Working Frame (ระบบพิกัดอ้างอิงที่ตั้งไว้ล่วงหน้า) หรือ Self (อ้างอิงตำแหน่งของ Object เองหลัง Placement) — เลือกให้ตรงกับสิ่งที่ต้องการ เช่น จัดวางชิ้นงานให้กึ่งกลาง Fixture ควรใช้ Geometric Center ไม่ใช่ Self

  1. 1เปิด Attribute ของ Tool ที่ Mount กับ Robot
  2. 2กำหนดค่า ExtTcp ให้ตรงกับตำแหน่งปลายจริงของ Tool (เช่น ปลายปืนเชื่อม หรือปลาย Gripper)
  3. 3ทดสอบ Jog หุ่นยนต์แล้วสังเกตว่าจุดหมุนอ้างอิงเปลี่ยนไปตาม ExtTcp ที่ตั้งใหม่

Approach / Departure และ Via Point

การเคลื่อนที่ตรงจากจุดหนึ่งไปอีกจุดหนึ่งอาจทำให้หุ่นยนต์ชนสิ่งกีดขวางระหว่างทาง จึงมักเพิ่มจุดกลาง:

จุดใช้ทำอะไร
Approachจุดก่อนถึงตำแหน่งจริง ให้หุ่นยนต์เข้าใกล้อย่างปลอดภัยก่อนหยิบ/วาง
Departureจุดหลังจากหยิบ/วางเสร็จ ให้หุ่นยนต์ถอยออกมาก่อนเคลื่อนที่ไปจุดถัดไป
Via Pointจุดผ่านระหว่างทาง ใช้บังคับเส้นทางให้อ้อมสิ่งกีดขวาง
Tip: ใส่ Approach/Departure ให้ทุก Operation ที่มี Fixture หรืออุปกรณ์อยู่ใกล้ตำแหน่งหยิบ-วาง แม้ Reach test จะผ่านก็ตาม เพราะเส้นทางตรงอาจตัดผ่านตัว Fixture ได้ในบางมุมของหุ่นยนต์
คำถามฝึกคิด: เปลี่ยน Gripper ตัวใหม่ที่ยาวกว่าเดิม 5 ซม. แล้วหุ่นยนต์ไปหยิบชิ้นงานพลาดตำแหน่งทุกจุด เกิดจากอะไร?
เฉลย: ลืมปรับค่า ExtTcp ให้ตรงกับความยาว Gripper ใหม่ — Pose เดิมที่ Teach ไว้อ้างอิงจาก TCP ของ Gripper ตัวเก่า พอเปลี่ยน Tool ต้องปรับ ExtTcp ก่อน ไม่ใช่ไป Teach ใหม่ทุกจุด
