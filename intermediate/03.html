3. Weld Point และ Weld Line Operation

วัตถุประสงค์การเรียนรู้

  1. แยกความแตกต่างของ Weld Point Operation และ Weld Line Operation ได้
  2. สร้างจุดเชื่อมและจัดการ Weld Gun Tip ได้

Weld Point Operation (Spot Welding)

งานเชื่อมจุด (Resistance Spot Welding) มีวงจรการทำงาน 3 ขั้นตอนต่อจุด: Motion (เคลื่อนที่เข้าจุดเชื่อม) → Welding (ปล่อยกระแสไฟเชื่อม) → Holding (กดค้างให้จุดเชื่อมเย็นตัว) — Process Simulate จำลองครบทั้ง 3 ขั้นตอนนี้ เมื่อสร้าง Weld Point Operation

สิ่งที่ต้องตั้งค่ารายละเอียด
Set Kinematics ของ Spot Gunกำหนดการเปิด-ปิดหน้าสัมผัส (Electrode) ของปืนเชื่อม
ประเภทปืนเชื่อมX Gun หรือ C Gun ตามรูปทรงของปืนที่ใช้งานจริง
Pose Editor / Tool Definitionกำหนดท่าทางและ TCP ของปืนเชื่อมให้ตรงกับปลาย Electrode จริง
Tip: เมื่อสร้าง Weld Point ผ่านคำสั่ง Create Weld Point โปรแกรมมีเครื่องมือ Pie Chart และ Automatic Approach Angle ช่วยแนะนำมุมเข้าจุดเชื่อมที่ปืนเชื่อมไม่ชนกับชิ้นงานหรือ Fixture โดยอัตโนมัติ ลองใช้ก่อนปรับมุมเอง

Weld Line Operation (Arc Welding)

งานเชื่อมอาร์กต่อเนื่องเป็นเส้น (Continuous Arc/Seam Welding) ต้องตั้งค่าพารามิเตอร์เฉพาะที่ Weld Point ไม่มี:

พารามิเตอร์ความหมาย
Travel Angle / Bisector Angleมุมเอียงของหัวเชื่อม (Torch) เทียบกับทิศทางเดินเชื่อมและแนวรอยต่อ
Torch Offsetระยะห่างจากปลาย Torch ถึงชิ้นงาน มาตรฐานทั่วไปอยู่ที่ประมาณ 10-20 มม.
TCPF (Tool Center Point Frame) ของ Torchกำหนดทิศทางเชื่อมผ่านเมนู Tools → Continuous → Location Orientation
ข้อควรระวัง: Weld Line/Arc Welding ต้องกำหนดความเร็วเคลื่อนที่ให้สม่ำเสมอตลอดแนว Welding Seam ไม่งั้นแนวเชื่อมจะหนา-บางไม่เท่ากัน ต่างจาก Weld Point ที่หุ่นยนต์หยุดนิ่งตอนเชื่อมแต่ละจุด — งานที่มีชิ้นงานทรงกระบอกหรือหมุนได้ มักใช้ External Axis (Positioner) หมุนชิ้นงานเข้าหา Torch แทนการขยับหุ่นยนต์รอบชิ้นงานทั้งหมด

การจัดการ Weld Gun Tip

ปืนเชื่อมแบบ Spot Weld มีปลาย Tip ที่สึกหรอได้จากการใช้งาน โปรแกรมจึงมีการตั้งค่า Tip Dress/Tip Change เป็นระยะ เพื่อจำลองว่าเมื่อไหร่ต้องหยุดเซลล์ไปเปลี่ยน/เจียร Tip ซึ่งกระทบ Cycle Time รวมของเซลล์ด้วย

Tip: เมื่อสร้างจุดเชื่อมจำนวนมากในเซลล์เดียว ให้จัดกลุ่มจุดที่อยู่ใกล้กันเรียงลำดับตามความต่อเนื่องของตำแหน่ง แทนการเรียงตามเลขจุดที่ลูกค้าให้มา จะช่วยลดระยะทางเคลื่อนที่รวมของหุ่นยนต์ได้มาก (ดูตัวอย่างจริงที่ Example File)
คำถามฝึกคิด: ทำไมงานเชื่อมตัวถังรถยนต์ส่วนใหญ่ใช้ Weld Point Operation มากกว่า Weld Line Operation?
เฉลย: โครงสร้างตัวถังรถยนต์ส่วนใหญ่เชื่อมแบบจุด (Spot Weld) เพราะแข็งแรงพอและเร็วกว่า ส่วน Weld Line มักใช้กับงานที่ต้องการรอยเชื่อมต่อเนื่องรับแรงสูง เช่น ตะเข็บถังหรือโครงสร้างที่ต้องกันรั่ว
