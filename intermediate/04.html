4. Sequence Editor และ PERT chart ขั้นกลาง

วัตถุประสงค์การเรียนรู้

  1. จัดลำดับ Operation แบบขนาน (Parallel) และต่อเนื่อง (Sequential) ใน PERT chart ได้
  2. กำหนด Time Attribute และมองเห็นผลต่อ Cycle Time รวม

Parallel และ Sequential Operation ใน PERT chart

PERT chart แสดงว่า Operation ไหนต้องรอ Operation ก่อนหน้าให้เสร็จก่อน (Sequential) และ Operation ไหนทำพร้อมกันได้ (Parallel) — การจัดกลุ่ม Operation ที่ไม่ได้พึ่งพากันจริงให้เป็น Parallel คือวิธีหลักในการลด Cycle Time รวมของเซลล์ โดยไม่ต้องเพิ่มอุปกรณ์

รูปแบบเมื่อไหร่ควรใช้
SequentialOperation ที่ผลลัพธ์ของอันก่อนหน้าจำเป็นต่ออันถัดไป เช่น ต้อง Pick ก่อนถึงจะ Place ได้
ParallelOperation ที่ทำงานคนละพื้นที่ คนละ Resource และไม่ต้องรอกัน เช่น หุ่นยนต์ 2 ตัวเชื่อมคนละฝั่งของชิ้นงาน

Time Attribute

แต่ละ Operation มี Time Attribute กำหนดเวลาที่ใช้ (เช่น เวลาเชื่อมต่อจุด, เวลาหยิบ-วาง) ค่านี้รวมกันตามลำดับใน PERT chart กลายเป็น Cycle Time ทั้งหมดของ Study — การมองเห็นว่า Operation ไหนกิน Time Attribute มากที่สุดคือจุดเริ่มต้นของการหาคอขวด

Object Flow Operation และ Set Current Operation

เมื่อ Study มี Part ไหลผ่านหลายสถานี (เช่น จากพาเลทต้นทาง ผ่านหุ่นยนต์ ไปจนถึงสายพานปลายทาง) ให้ใช้ Object Flow Operation กำหนดเส้นทางการไหลของ Part ตลอดทั้งเซลล์ในภาพเดียว แทนการไล่ดูทีละ Operation ส่วน Set Current Operation คือคำสั่งที่ใช้สลับไปดู/แก้ไข Operation ใดๆ ใน Sequence Editor ได้ทันที โดยไม่ต้องรันจากต้นทุกครั้งเมื่อต้องการโฟกัสแก้เฉพาะจุด

Tip: ใช้ Export to Web ส่งออกลำดับ Operation และผล Cycle Time เป็นหน้าเว็บดูง่าย เหมาะเวลาต้อง รายงานผลให้ทีมที่ไม่ได้ใช้ Process Simulate โดยตรงดูความคืบหน้า
Tip: ก่อนจะไปปรับ Path ให้เร็วขึ้น ลองดู PERT chart ก่อนว่ามี Operation ที่ควรขนานกันได้แต่ดันเรียงต่อกันอยู่หรือไม่ — มักลด Cycle Time ได้มากกว่าการปรับความเร็วหุ่นยนต์เพียงอย่างเดียว
คำถามฝึกคิด: เซลล์มี Robot A เชื่อมจุดฝั่งซ้ายและ Robot B เชื่อมจุดฝั่งขวาของชิ้นงานเดียวกัน แต่ถูกตั้งใน PERT chart แบบ Sequential (B ต้องรอ A เชื่อมเสร็จก่อน) จะเกิดผลอะไร และแก้ได้อย่างไร?
เฉลย: Cycle Time รวมจะสูงเกินจำเป็นเพราะ Robot B ว่างงานระหว่างรอ A ทั้งที่ทำงานคนละฝั่งไม่ชนกัน — ถ้าตรวจสอบด้วย Collision Set (บทที่ 5) แล้วพบว่าไม่มีจุดชน ให้ปรับ PERT chart เป็น Parallel เพื่อให้ทั้งสองตัวเชื่อมพร้อมกัน
