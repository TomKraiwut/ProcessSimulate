6. Resource Library และการนำกลับมาใช้ซ้ำ

วัตถุประสงค์การเรียนรู้

  1. เก็บ Robot, Gripper, Fixture มาตรฐานไว้ใน Resource Library ได้
  2. นำ Resource จาก Library กลับมาใช้ซ้ำข้าม Study ได้โดยไม่ต้องสร้างใหม่ทุกครั้ง

Resource Library และการนำกลับมาใช้ซ้ำ

เก็บ Robot, Gripper, Fixture มาตรฐานไว้ใน Resource Library กลาง แล้วดึงมาใช้ข้าม Study/โปรเจกต์ได้ โดยไม่ต้องสร้างใหม่ทุกครั้ง ช่วยให้ทีมงานหลายคนใช้ทรัพยากรชุดเดียวกันสอดคล้องกัน

ในเชิงโครงสร้างไฟล์ Library ถูกจัดเก็บเป็น Library Root Folder ที่รวมโฟลเดอร์ย่อยของ Component และไฟล์อื่นๆ โดยแต่ละชิ้น Resource คือ Component (ไฟล์ .CO / .COJT) — เวลาต้องการหุ่นยนต์หรืออุปกรณ์มาตรฐาน สามารถดึงจาก Asset Library ที่ Siemens จัดเตรียม Component สำเร็จรูปไว้ให้ดาวน์โหลดใช้ได้ทันที แทนการสร้าง Kinematics เองตั้งแต่ศูนย์ (ดูขั้นตอน Download Asset and Robot ที่ Intermediate บทที่ 1)

ประโยชน์รายละเอียด
ลดเวลาสร้างโมเดลซ้ำRobot/Gripper รุ่นเดียวกันถูกสร้างและตั้งค่าไว้ครั้งเดียว ใช้ได้หลาย Study
ความสอดคล้องของข้อมูลทีมทุกคนใช้ข้อมูล Payload/Reach ของอุปกรณ์ชุดเดียวกัน ลดความผิดพลาดจากการพิมพ์ค่าเอง
ง่ายต่อการอัปเดตแก้ค่าที่ Library ครั้งเดียว โครงการที่ดึงไปใช้ภายหลังได้ค่าที่อัปเดตแล้ว
Tip: ตั้งชื่อ Resource ใน Library ให้สื่อความหมายเสมอ เช่น Robot_ABB_IRB6700_150kg เพราะเมื่อ Library มี Resource หลายร้อยตัว การไล่หาโดยไม่มีชื่อที่ชัดเจนจะยากมาก
คำถามฝึกคิด: ทีมมี Study 5 ไฟล์ที่ใช้ Robot รุ่นเดียวกัน แต่ตั้งค่า Payload ไม่ตรงกันทุกไฟล์ ควรแก้ปัญหานี้อย่างไร ไม่ให้เกิดซ้ำในอนาคต?
เฉลย: รวม Robot รุ่นนั้นเข้า Resource Library กลางค่าเดียว แล้วให้ทุก Study ดึงจาก Library แทนการสร้าง Resource แยกเองในแต่ละไฟล์ — ป้องกันค่าตั้งต้นเพี้ยนกันระหว่างไฟล์ตั้งแต่ต้น
