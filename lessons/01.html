Process Simulate Tutorial

01. Part Assembly

วัตถุประสงค์การเรียนรู้

  1. ตั้ง System Root แล้ววางชิ้นส่วนด้วย Placement Manipulator (ลาก / พิมพ์ค่า) และ Relocate (Frame by 6 values)
  2. สร้าง Compound Operation และ Object Flow Operation แล้วเพิ่มจุดด้วย Add Location Before ใน Path Editor
  3. ต่อ operation ด้วย Link ใน Sequence Editor แล้วเล่นผลด้วย Set Current Operation (3 ชิ้น = 15 วินาที)
  4. แยกชิ้นส่วน PLC ด้วย Automatic Disassembly และใช้ Display Event ให้ชิ้นส่วนโผล่ตามลำดับประกอบ (6 ชิ้น = 30 วินาที)

ประกอบชิ้นส่วน 2 ชุดทีละขั้น รวม 20 ขั้น — ชุด BASIC (3 ชิ้นลงบน BASE) ฝึกวางและสร้าง operation และชุด PLC (6 ชิ้น) ฝึกแยกชิ้นอัตโนมัติและแสดงลำดับประกอบ

ภาพรวม: ประกอบชิ้นส่วนชุด BASIC และชุด PLC

ขั้นที่ 1: ตั้ง System Root ให้ชี้ไปที่โฟลเดอร์ Library

  1. 1เมนู File เลือก Options
  2. 2เลือกหน้า Disconnected
  3. 3Client System Root กดปุ่ม... เลือกโฟลเดอร์ Library ของบทเรียน (ในภาพคือ ...\01_PART_ASSEMBLY\Library)
  4. 4กด OK
ข้อควรจำ: ค่าใหม่มีผลตอนเปิดไฟล์ครั้งถัดไปและใช้ร่วมกับโปรแกรม Tecnomatix อื่นในเครื่อง ถ้าชี้ผิดที่ PS จะหาไฟล์ชิ้นส่วน .cojt ไม่เจอ

ขั้นที่ 2: เปิดไฟล์ BASIC_0_ASSEMBLY.psz

  1. 1เมนู File > Disconnected Study
  2. 2Open in Standard Mode
  3. 3เลือก BASIC_0_ASSEMBLY
  4. 4กด Open
ระวัง: ถ้ามีไฟล์เปิดอยู่ PS จะถามว่าจะ Save ไฟล์เดิมไหม ตอบ No ถ้าไม่ต้องการเก็บสิ่งที่ลองทำ

เป้าหมายบท 0: วางชิ้นส่วน 3 ชิ้นเข้าที่บน BASE

  1. 1CYLENDER ใช้ Placement Manipulator (ขั้นที่ 3)
  2. 2CUBOID ใช้ Placement พิมพ์ตัวเลข (ขั้นที่ 4)
  3. 3TRIANGURA ใช้ Relocate (ขั้นที่ 5)

ขั้นที่ 3: Placement Manipulator เลื่อน CYLENDER ลงหลุม

  1. 1เลือก CYLENDER ใน Objects แล้วกด Placement Manipulator บน toolbar ของหน้าจอ 3D
  2. 2เลือกแกน X
  3. 3พิมพ์ 150 แล้วกด Enter
  4. 4Frame of Reference = Self (ค่าเริ่มต้น)
  5. 5กด Close
  6. 6CYLENDER ลงหลุมพอดี
หมายเหตุ: ลากลูกศรในหน้าจอ 3D ก็เลื่อนได้ แต่พิมพ์ตัวเลขจะได้ตำแหน่งตรงกับไฟล์เฉลย

ขั้นที่ 4: Placement พิมพ์ตัวเลขวาง CUBOID ลงช่องเอียง

  1. 1เลือก CUBOID เปิด Placement Manipulator แล้วกดลูกศรมุมล่างซ้ายเพื่อขยาย
  2. 2แถวล่าง = มุมหมุน Rx Ry Rz พิมพ์ Rx = 45 ก่อน
  3. 3แถวบน = ตำแหน่ง X Y Z พิมพ์ -150, 12.28, 46.20
  4. 4CUBOID เข้าช่องพอดี แล้วกด Close
ระวัง: พิมพ์มุมหมุนก่อน แล้วค่อยพิมพ์ตำแหน่ง และลบค่าเดิมในช่องให้หมดก่อนพิมพ์ (ถ้ามีเครื่องหมาย - ค้างในช่อง Z จะได้ -46.20 ต้องพิมพ์ใหม่)

ขั้นที่ 5: Relocate ย้าย TRIANGURA ไปที่ frame จาก 6 ค่า

  1. 1From frame = Self
  2. 2To frame กดลูกศรข้างช่อง
  3. 3Frame by 6 values
  4. 4แถวล่าง Rx = 60
  5. 5แถวบน 0, -8.53, -170.71
  6. 6กด OK

ขั้นที่ 5 (ต่อ): กด Apply แล้ว TRIANGURA เข้าร่อง

  1. 1กด Apply
  2. 2กด Close
  3. 3TRIANGURA เข้าร่องบน BASE ครบ 3 ชิ้น
ข้อควรจำ: ถ้าจะเก็บงานใช้ File > Disconnected Study > Save As ชื่อใหม่ อย่าบันทึกทับไฟล์ตัวอย่าง

ขั้นที่ 6: สร้าง Compound Operation ชื่อ CompOp

  1. 1เปิดไฟล์ BASIC_1 แท็บ Operation กดลูกศรใต้ New Operation
  2. 2New Compound Operation
  3. 3Name = CompOp
  4. 4Scope = Operation Root
  5. 5กด OK
ข้อควรจำ: Compound Operation คือกล่องรวม operation ย่อย ใช้เป็นตัวที่ Set Current แล้วเล่นงานประกอบทั้งชุดในครั้งเดียว

ขั้นที่ 7: New Object Flow Operation ให้ CYLENDER

  1. 1เลือก CYLENDER แล้ว New Operation > New Object Flow Operation
  2. 2Name ตั้งให้เป็น CYLENDER_Op
  3. 3Object = CYLENDER
  4. 4Scope คลิกช่องให้เป็นสีเขียวแล้วคลิก CompOp ใน Operation Tree
  5. 5Start Point = จุดเหนือหลุม (ขั้นที่ 8)
  6. 6End Point = จุดประกอบ 0, 0.02, 60
  7. 7กด OK

ขั้นที่ 8: Start Point เหนือหลุม 150 mm ได้ทางเดินแนวตั้ง

  1. 1Start Point ลูกศร > Frame by 6 values
  2. 2พิมพ์ 0, 0.02, 210 แล้ว OK
  3. 3กด OK ที่หน้าต่าง Object Flow
  4. 4จุดเริ่ม: เหนือหลุม 150 mm
  5. 5จุดจบ: ในหลุม
ระวัง: ช่อง Start Point เริ่มต้นเป็น Current Location (ตำแหน่งที่ประกอบแล้ว) ถ้าไม่เปลี่ยน ชิ้นงานจะไม่ลอยขึ้นมาก่อน

ขั้นที่ 9: เปิด CYLENDER_Op ใน Path Editor

  1. 1เลือก CYLENDER_Op ใน Operation Tree
  2. 2แท็บ Path Editor กด Add Operations to Editor (ปุ่มซ้ายสุด)
  3. 3loc = จุดเริ่ม loc1 = จุดจบ
ข้อควรจำ: ถ้าเลือก CompOp แล้วกด Add จะเห็นทุก operation ในกล่องพร้อมกัน (ดูได้ในไฟล์ BASIC_2)

ขั้นที่ 10: คลิกขวาที่ loc1 แล้ว Add Location Before

  1. 1ใน Path Editor คลิกขวาที่ loc1 (จุดจบ)
  2. 2Add Location Before
  3. 3ได้ loc2 แทรกระหว่าง loc กับ loc1 ที่ตำแหน่งเดียวกับ loc1
หมายเหตุ: หน้าต่าง Placement Manipulator ของ loc2 เปิดขึ้นเองทันที ใช้เลื่อนจุดใหม่ในขั้นถัดไป

ขั้นที่ 11: ยก loc2 ขึ้น 30 mm เป็นจุดชะลอก่อนลงหลุม

  1. 1เลือกแกน Z
  2. 2พิมพ์ 30 แล้วกด Enter
  3. 3ช่อง Z ของตำแหน่งเปลี่ยนจาก 60 เป็น 90
  4. 4กด Close
  5. 5ทางเดินเป็น 3 จุด: บน > จุดชะลอ > ในหลุม

ขั้นที่ 12: Set Current Operation แล้วเล่น simulation

  1. 1เลือก CompOp
  2. 2แท็บ Operation กด Set Current Operation
  3. 3Jump Simulation to Start
  4. 4Play Simulation Forward
  5. 5CYLENDER เลื่อนลง loc > loc2 > loc1
ระวัง: ถ้าขึ้น Previous simulation is not reset ให้ตอบ Yes ก่อน ไม่อย่างนั้นกด Play แล้วชิ้นงานจะค้างอยู่ที่เดิม

ขั้นที่ 13: ทำซ้ำกับ CUBOID, TRIANGURA แล้ว Link ใน Sequence Editor

  1. 1Object Flow ให้ CUBOID และ TRIANGURA แบบเดียวกัน (Scope = CompOp)
  2. 2Sequence Editor เลือก operation 2 ตัวตามลำดับแล้วกด Link
  3. 3ผล: ต่อกัน 0-5, 5-10, 10-15 วินาที

ขั้นที่ 14: เปิด BASIC_2 ดูลำดับประกอบครบ 15 วินาที

  1. 1CYLENDER 0-5 วินาที
  2. 2CUBOID 5-10 วินาที
  3. 3TRIANGURA 10-15 วินาที
  4. 4เวลารวม 15.00 วินาที
ข้อควรจำ: เปิดไฟล์แล้วเลือก CompOp > Set Current Operation > Jump to Start ก่อนกด Play ทุกครั้ง

ขั้นที่ 15: เลือกชิ้นส่วน PLC 6 ชิ้นแล้วกด Automatic Disassembly

  1. 1เปิด PLC_1_ASSEMBLY.psz แล้วคลิก PLC_Body
  2. 2กด Shift ค้างแล้วคลิก PLC_PCB (เลือกครบ 6 ชิ้น)
  3. 3แท็บ Process กลุ่ม Assembly กด Automatic Disassembly
ระวัง: ถ้าเลือกแค่โฟลเดอร์ Parts ปุ่มจะยังเป็นสีเทา ต้องเลือกตัวชิ้นส่วน

ขั้นที่ 16: ตั้งค่า 3 แท็บในหน้าต่าง Automatic Disassembly

  1. 1Objects ติ๊กชิ้นที่จะแยก (ครบ 6)
  2. 2Explosion Distance = Automatic
  3. 3Explosion Direction = 2D Horizontal
  4. 4Sequence Name = Assembly
  5. 5Sequence Type ติ๊ก Assembly และ Disassembly
  6. 6Operation Linkage = Parallel
  7. 7กด Explode
หมายเหตุ: ทุกค่าในภาพเป็นค่าเริ่มต้นของ PS ไม่ได้เปลี่ยน

ขั้นที่ 17: ผลลัพธ์ชิ้นส่วนแยกออกและได้ Assembly_out / Assembly_in

  1. 1ชิ้นส่วน 6 ชิ้นถูกแยกออกไปตามแนวนอน
  2. 2เส้นทางพากลับเข้าตำแหน่งประกอบเดิม
  3. 3Assembly_out สร้างจาก Disassembly
  4. 4Assembly_in ทุกชิ้นเคลื่อนเข้าพร้อมกัน (Parallel) 5 วินาที

ขั้นที่ 18: เปิด PLC_2 ดูลำดับประกอบ 6 ชิ้นทีละชิ้น

  1. 1Assembly_0_in มี 6 operation ต่อกันด้วย Link ตัวละ 5 วินาที
  2. 2จุดแดงที่ต้นแถบ = Event ที่ทำให้ชิ้นส่วนโผล่ขึ้นมา (ขั้นที่ 20)
  3. 3จบที่ 30 วินาที

ขั้นที่ 19: คลิกขวาที่แถบ operation แล้ว Display Event

  1. 1คลิกขวาที่แถบ PLC_PCB_in ใน Sequence Editor
  2. 2Display Event (Ctrl+D)
  3. 3คลิกชิ้นส่วนใน Objects (PLC_PCB) ให้ขึ้นในรายการ
  4. 4Start Time = 0
  5. 5After Start of Task
  6. 6กด OK
หมายเหตุ: Start Time เริ่มต้นเป็นตำแหน่งที่คลิกขวาบนแถบ (ในภาพเดิมขึ้น 2.45) ตอนทำภาพกด Cancel เพราะ PLC_2 มี Event อยู่แล้ว ใช้ Blank Event (Ctrl+B) เมื่อต้องการซ่อนชิ้นส่วน

ขั้นที่ 20: เล่น simulation ชิ้นส่วนโผล่ขึ้นตามลำดับ

  1. 1ช่องขาว = ชิ้นที่ยังถูกซ่อน
  2. 2ช่องดำ = ชิ้นที่แสดงอยู่

เปิด .psz แล้วชิ้นส่วนไม่ขึ้นตั้ง System Root ให้ชี้โฟลเดอร์ Library แล้วเปิดไฟล์ใหม่ (ขั้นที่ 1)
พิมพ์ค่าแล้วได้เลขติดลบ/ตำแหน่งผิดลบค่าเดิมในช่องให้หมดก่อนพิมพ์ และพิมพ์มุมหมุนก่อนตำแหน่ง
คลิกชิ้นงานแล้วช่อง End Point ไม่ขึ้นชิ้นงานที่กำลังจะเคลื่อนที่ใช้เป็นจุดไม่ได้ ให้ใช้ Frame by 6 values (ขึ้นค่าจุดที่คลิกไว้)
Scope ไม่มี CompOp ให้เลือกคลิกช่อง Scope ให้เป็นสีเขียวแล้วคลิก CompOp ใน Operation Tree
ทางเดินพุ่งผิดทิศจุดใช้ frame ผิด เลือก operation กด Delete > Yes แล้วสร้างใหม่ (Ctrl+Z ไม่ได้ลบ operation ในการทดสอบนี้)
กด Play แล้วชิ้นงานไม่ขยับตอบ Yes ที่ Previous simulation is not reset แล้ว Set Current Operation และ Jump to Start
Automatic Disassembly เป็นสีเทาเลือกตัวชิ้นส่วน (คลิก + Shift คลิก) ไม่ใช่โฟลเดอร์ Parts
ปิดไฟล์แล้วถาม SaveNo = ไม่เก็บสิ่งที่ลอง ถ้าจะเก็บใช้ Save As ชื่อใหม่ ไม่ทับไฟล์ตัวอย่าง
