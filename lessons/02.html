02. Kinematics

วัตถุประสงค์การเรียนรู้

  1. เปิด Device ให้แก้ไขได้ด้วย Set Modeling Scope แล้วสร้าง Link และ Joint ใน Kinematics Editor
  2. ตั้ง Pose (HOME, DOWN, UP, PLACE) ด้วย Pose Editor และจบงานด้วย End Modeling
  3. สั่ง Device Operation จาก pose ไป pose แล้วต่อ 6 operation ด้วย Link (รวม 32 วินาที)
  4. ใช้ Attach / Detach Event ให้ชิ้นงานติดไปกับหัวจับ แล้วอัดวิดีโอและ Export to Web

เปลี่ยนชิ้นส่วนที่นิ่งอยู่ให้เป็นเครื่องที่ขยับได้ — สร้างกลไก gantry แกน X / Z ทีละขั้น รวม 17 ขั้น แล้วสั่งให้หยิบ-วางกล่อง ตั้งแต่ Link, Joint, Pose ไปจนถึง Device Operation และ Event

ภาพรวม: สร้างกลไก gantry แล้วสั่งหยิบ-วางชิ้นงาน

ขั้นที่ 1: ตั้ง System Root แล้วเปิด 1_Modeling.psz

  1. 1หน้า Welcome (Home > Welcome Page) มีรายการ Recent Files
  2. 2คลิก 1_Modeling
  3. 3System Root ต้องชี้โฟลเดอร์ 02_KINEMATICS\Library
  4. 4เปิดแล้วเห็น gantry และกล่องแดง (Part)

ขั้นที่ 2: เลือก Device แล้วกด Set Modeling Scope

  1. 1แท็บ Modeling
  2. 2เลือก Device ใน Objects แล้วกด Set Modeling Scope
  3. 3Device มีชิ้นส่วน 5 ตัว: TCPF (frame), Conveyor, Z, X, Body
  4. 4ทุกชิ้นยังเป็นก้อนเดียวกัน ยังขยับไม่ได้
  5. 5ช่อง Scope เปลี่ยนเป็น Device ปุ่มสร้าง geometry ใช้ได้แล้ว
ข้อควรจำ: Modeling Scope คือการเปิด component ให้แก้ไขได้ ทำทีละ component เมื่อเสร็จต้อง End Modeling (ขั้นที่ 10)

ขั้นที่ 3: เปิด Kinematics Editor แล้วกด Create Link

  1. 1Device ยังเลือกอยู่ กด Kinematics Editor
  2. 2ปุ่มแรกซ้ายบน = Create Link
  3. 3กล่อง lnk1 ขึ้นในกราฟ
  4. 4หน้าต่าง Link Properties ชื่อ lnk1 (เปลี่ยนชื่อได้)
  5. 5แถวสีเขียวใน Link Elements รอให้คลิกชิ้นส่วน (ขั้นที่ 4)
หมายเหตุ: ย้ายหน้าต่าง Kinematics Editor และ Link Properties ออกไปด้านขวา ไม่ให้บัง Objects tree

ขั้นที่ 4: lnk1 = Body + Conveyor (ส่วนที่อยู่นิ่ง)

  1. 1คลิก Body ใน Objects
  2. 2คลิก Conveyor
  3. 3ทั้ง 2 ชิ้นขึ้นในรายการ แถวเขียวเลื่อนลงรอชิ้นถัดไป
  4. 4กด OK
ระวัง: tree เลื่อนขึ้นลงหลังคลิกแต่ละครั้ง ดูชื่อก่อนคลิกชิ้นถัดไป ถ้าคลิกผิด (ในภาพเคยได้ TCPF) ให้คลิกชื่อนั้นในรายการแล้วกด Delete

ขั้นที่ 5: lnk2 = X และ lnk3 = Z + TCPF

  1. 1lnk1 สีส้ม = ฐาน
  2. 2lnk2 สีเขียว = แคร่แกน X
  3. 3lnk3 สีเหลือง = หัวจับแกน Z
  4. 4สีในหน้าจอ 3D ตรงกับสีของ link

ขั้นที่ 6: ลากจาก lnk1 ไป lnk2 สร้าง joint j1 (แกน X)

  1. 1กดค้างที่ lnk1
  2. 2ลากไปปล่อยที่ lnk2 หน้าต่าง Joint Properties เปิดขึ้น
  3. 3Name = j1
  4. 4แกน From 0,0,0 To = -100, 0, 0 (ทิศ -X)
  5. 5Joint type = Prismatic (เลื่อน)
  6. 6ลูกศรล่างซ้ายเปิดส่วน Limits แล้ว Limits type = Constant
  7. 7High limit = 250 Low limit = 0
  8. 8กด OK

ขั้นที่ 7: ลากจาก lnk2 ไป lnk3 สร้าง j2 (แกน Z ลง)

  1. 1Parent = lnk2 Child = lnk3
  2. 2แกน To = 0, 0, -100 (ทิศลง -Z)
  3. 3Prismatic
  4. 4Constant 0 ถึง 95 แล้ว OK
  5. 5เส้น j1 lnk1 > lnk2
  6. 6เส้น j2 lnk2 > lnk3

ขั้นที่ 8: Pose Editor > New ตั้งค่า joint แล้วตั้งชื่อ pose

  1. 1เลือก Device กด Pose Editor (มี HOME อยู่แล้ว)
  2. 2กด New หน้าต่าง Joint Jog เปิด
  3. 3พิมพ์ j2 = 95 (หรือลากแถบ)
  4. 4Lower / Upper Limit = ค่าที่ตั้งในขั้น 6-7
  5. 5Pose name = DOWN
  6. 6กด OK
  7. 7หัวจับลงถึงกล่องแดงพอดี = ทิศ j2 ถูก

ขั้นที่ 9: สร้างให้ครบ 4 pose แล้ว Jump กลับ HOME

  1. 1รายการมี HOME DOWN UP PLACE (HOME = j1 0, j2 0 มีมาตั้งแต่แรก)
  2. 2เลือก HOME กด Jump ให้เครื่องกลับท่าเริ่มแล้ว Close
ระวัง: ใช้ชื่อ pose ตามนี้ทุกตัวอักษร บท 1 อ้างชื่อเหล่านี้

ขั้นที่ 10: End Modeling และการบันทึก (อธิบาย)

  1. 1End Modeling (แท็บ Modeling) = ปิดโหมดแก้ไขและเก็บกลไกลงไฟล์ชิ้นส่วน .cojt ใน Library
  2. 2คำถาม Save ไฟล์ .psz: ตอบ No ถ้าเป็นการฝึก หรือใช้ Save As ชื่อใหม่ ถ้าจะเก็บงาน
ระวัง: Library\Device.cojt ใช้ร่วมกับ 2_Device_Operation (ไฟล์เฉลย) ถ้า End Modeling แล้วบันทึกทับไฟล์เฉลยจะเปลี่ยนตาม ในห้องเรียนให้คัดลอกโฟลเดอร์ 02_KINEMATICS ไว้ก่อน

ขั้นที่ 11: เปิด 2_Device_Operation แล้ว New Device Operation

  1. 1เลือก Device แท็บ Operation > ลูกศร New Operation
  2. 2New Device Operation
  3. 3Name ตั้งชื่อ (ไฟล์ตัวอย่างใช้ชื่อ pose ปลายทาง)
  4. 4Device = Device
  5. 5From pose = ท่าปัจจุบัน
  6. 6To pose = DOWN
  7. 7Duration = 5 วินาที (ลูกศรล่างซ้ายเปิดส่วนนี้)
  8. 8กด OK

ขั้นที่ 12: ได้ Device_Op 5 วินาที กด Play หัวจับลงหยิบ

  1. 1Device_Op ขึ้นใน Operation tree และถูกตั้งเป็น current operation ให้เอง
  2. 2แถบใน Sequence Editor ยาว 5 วินาที
  3. 3กด Play Simulation Forward
  4. 4ที่ 5.00 วินาที หัวจับอยู่ที่ DOWN (แต่ยังไม่จับกล่อง ต้องมี Attach Event)
หมายเหตุ: ตอนทำภาพลบ Device_Op ทิ้ง (เลือกแล้วกด Delete) เพราะไฟล์มีชุดเฉลยใน CompOp อยู่แล้ว

ขั้นที่ 13: CompOp = 6 Device Operation ต่อกันด้วย Link รวม 32 วินาที

  1. 1เลือก CompOp > Set Current Operation ลำดับ DOWN > HOME > UP > PLACE > UP > HOME
  2. 2ลูกศรดำ = Link (เลือก 2 operation ใน Sequence Editor แล้วกดปุ่ม Link)
  3. 3จุดแดง = Attach Event ตอนจบ DOWN
  4. 4จุดแดง = Detach Event ตอนเริ่ม UP ตัวที่ 2
  5. 5จบที่ 32 วินาที = 6 × 5 + รอ 1 วินาที 2 ครั้ง

ขั้นที่ 14: Attach Event ให้กล่องติดไปกับ lnk3

  1. 1คลิกแถบ DOWN ใน Sequence Editor ก่อนแล้วกดลูกศร New Event
  2. 2Attach Event = หยิบ
  3. 3Detach Event = ปล่อย
  4. 4Objects to Attach คลิก Part
  5. 5To Object คลิกช่องแล้วคลิก lnk3
  6. 6Start Time = 0
  7. 7Before End of Task แล้ว OK Detach ทำแบบเดียวกันที่แถบ UP ตัวที่ 2: Detach Event, Objects = Part, After Start of Task 0 กล่องจะหลุดจากหัวจับตอนเริ่มยกขึ้น

ขั้นที่ 15: เล่น CompOp ดูหยิบ-วางครบรอบ

  1. 1Jump Simulation to Start
  2. 2Play Simulation Forward
  3. 3ดูกล่องติดไปกับหัวจับหลัง DOWN และอยู่ที่แผ่นอีกฝั่งหลัง UP
  4. 4จบ 32.00 วินาที หัวจับกลับ HOME

ขั้นที่ 16: Record Video ด้วย Movie Recorder

  1. 1แท็บ Operation > Movie Recorder แล้วกดเฟือง (Settings)
  2. 2ปุ่มแดง = Record แล้วกด Play ใน Sequence Editor
  3. 3Stop เมื่อเล่นจบ
  4. 4ป้าย REC ขึ้นในหน้าจอ 3D ระหว่างอัด
  5. 5Destination โฟลเดอร์ที่เก็บไฟล์
  6. 6Format MPEG-4 (.mp4)
  7. 7ความละเอียด FullHD
  8. 8OK

ขั้นที่ 17: Export to Web ส่งงานให้คนที่ไม่มี Process Simulate

  1. 1File > Import / Export
  2. 2Export to Web
  3. 3File name ตั้งชื่อ .html
  4. 4Launch in browser
  5. 5Level of details Low = ไฟล์เล็ก
  6. 6Include simulation Operation = CompOp
  7. 7OK
ผลลัพธ์: KINEMATICS_WebView.html (9 MB) ในโฟลเดอร์คือไฟล์ที่ส่งออกไว้เปิดด้วย browser หมุนดูโมเดลและเล่น simulation ได้

ปัญหาที่พบบ่อยและวิธีแก้

อาการวิธีแก้
Kinematics Editor เป็นสีเทายังไม่ได้ Set Modeling Scope หรือไม่ได้เลือก Device
หน้าต่างบัง Objects treeลากหน้าต่าง Kinematics Editor / Link Properties ไปด้านขวาก่อนคลิกชิ้นส่วน
ได้ชิ้นส่วนผิดใน Link Elementstree เลื่อนหลังคลิก คลิกชื่อผิดในรายการแล้วกด Delete
Joint type / Limits type ไม่เปลี่ยนเปิดรายการแล้วคลิกที่ชื่อ (ลูกศรขึ้นลงบนคีย์บอร์ดไม่เลือกให้)
Joint Jog แล้วเลื่อนผิดทิศแก้แกน To ของ joint (เช่น -100 แทน 100) ใน Kinematics Editor
New Event / Attach Event เป็นสีเทาคลิกแถบ operation ใน Sequence Editor ก่อน
เพิ่ม Event ผิดแล้ว Ctrl+Z ไม่หายเปิดไฟล์ใหม่ (Welcome > Recent Files) แล้วตอบ No ที่คำถาม Save
ปิดไฟล์แล้วถาม SaveNo = ไม่เก็บสิ่งที่ลอง ถ้าจะเก็บใช้ Save As ชื่อใหม่
