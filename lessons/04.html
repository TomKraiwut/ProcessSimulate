04. Robot and Gripper

วัตถุประสงค์การเรียนรู้

  1. สร้างกลไกของ CNC และ Gripper ด้วย Kinematics Editor, Joint Dependency และ Pose (OPEN / CLOSE)
  2. ใส่หุ่น HP20D ด้วย Insert Component, Placement แล้วติด Gripper ด้วย Mount Tool
  3. สร้างงานโหลดเข้า-ออก: Compound, Object Flow, Device Operation, Generic Robotic Operation และ Pick and Place
  4. ดูและแก้ Motion Type / Speed / OLP Commands ใน Path Editor และ Teach Pendant
  5. สร้าง Collision Set ตั้ง Collision Options แล้วเล่นทั้งชุด (36.27 วินาที ไม่ชน)

เซลล์ที่มีเครื่อง CNC, Gripper และหุ่น HP20D — ทำทีละขั้น รวม 29 ขั้น ตั้งแต่สร้างกลไก ใส่หุ่นและติด Gripper สั่งหุ่นหยิบชิ้นงานเข้า-ออกเครื่อง CNC ไปจนถึงตรวจชน

ขั้นที่ 2: ไฟล์ 1 ยังไม่มีกลไก Pose Editor จึงเป็นสีเทา

  1. 1mGripper และ mCNC ใน Resources (ไฟล์ 1)
  2. 2Kinematics Editor กดได้
  3. 3Pose Editor สีเทา = ยังไม่มี joint ให้ตั้งท่า
  4. 4เป้าหมาย (ไฟล์ 2): lnk1
  5. 5lnk2 ต่อด้วย joint j1

ขั้นที่ 3: Set Modeling Scope ที่ mCNC แล้วดูชิ้นส่วนข้างใน

  1. 1เลือก mCNC > Set Modeling Scope
  2. 2ช่อง Scope = mCNC
  3. 3CNC ตัวเครื่อง
  4. 4DoorL ประตูซ้าย
  5. 5DoorR ประตูขวา
  6. 6คลิก DoorL ใน tree ชิ้นนั้นจะสว่างในหน้าจอ 3D
ข้อควรจำ: Modeling Scope เปิดชิ้นส่วนให้แก้ไขได้ทีละชิ้น ต้องอยู่ใน Scope ก่อน Kinematics Editor ถึงจะสร้าง link ได้

ขั้นที่ 4: Kinematics Editor > Create Link ทั้ง 3 link

  1. 1Create Link (ปุ่มแรกในหน้าต่าง)
  2. 2Name = lnk1 (ขึ้นเอง)
  3. 3แถวสีเขียว Link Elements แล้วคลิก CNC ใน tree
  4. 4OK
  5. 5lnk1 = CNC
  6. 6lnk2 = DoorL
  7. 7lnk3 = DoorR
ทำซ้ำ: กด Create Link อีก 2 ครั้ง ครั้งที่ 2 คลิก DoorL ครั้งที่ 3 คลิก DoorR สี link ในกราฟตรงกับสีในหน้าจอ 3D

ขั้นที่ 5: ลาก lnk1 ไป lnk2 สร้าง j1 แบบ Prismatic แกน -Y

  1. 1กดค้างที่ lnk1 ลากไปปล่อยที่ lnk2 ได้ joint j1
  2. 2แกน From 0,0,0 To 0, -100, 0 (ทิศ -Y)
  3. 3Joint type = Prismatic (เลื่อน)
  4. 4Limits = No limits
  5. 5OK
  6. 6j1 lnk1 > lnk2
  7. 7j2 lnk1 > lnk3 แกน To 0, 100, 0 (ทิศ+Y)

ขั้นที่ 6: Joint Dependency ให้ j2 ขยับตาม j1

  1. 1เลือกเส้น j2 ในกราฟ > ปุ่ม Joint Dependency > เลือก Joint Function
  2. 2ลูกศรข้าง Joint Name > คลิก j1
  3. 3คลิกปุ่ม j1 เพื่อใส่ลงสูตร
  4. 4สูตรขึ้นเป็น (D(j1)) = ระยะเลื่อนของ j1
  5. 5Apply แล้ว Close

ขั้นที่ 7: Pose Editor ของ CNC: OPEN j1 = 400, CLOSE j1 = 0

  1. 1Pose Editor > New... > พิมพ์ 400 แล้วกด Tab
  2. 2Pose name ลบชื่อเดิมแล้วพิมพ์ OPEN
  3. 3OK
  4. 4OPEN
  5. 5CLOSE = 0 (ทำซ้ำข้อ 1-3)
  6. 6Jump ทดสอบทีละท่า

ขั้นที่ 8: Gripper: link 2 ตัวและ j1 แบบ Prismatic แกน -X

  1. 1Gripper_Clamp
  2. 2Gripper_Base
  3. 3lnk1 = Gripper_Base
  4. 4lnk2 = Gripper_Clamp
  5. 5To -100, 0, 0 (ทิศ -X)
  6. 6Prismatic แล้ว OK

ขั้นที่ 9: Pose ของ Gripper: OPEN j1 = 20, CLOSE j1 = 0

  1. 1New... > 20 แล้ว Tab
  2. 2ชื่อ OPEN > OK
  3. 3OPEN
  4. 4CLOSE = 0
  5. 5Jump OPEN: Clamp เลื่อนออก 20 mm

ขั้นที่ 10: End Modeling และการไม่บันทึกทับ (อธิบาย)

  1. 1End Modeling = ปิดโหมดแก้ไขของชิ้นที่อยู่ใน Scope
  2. 2ช่อง Scope บอกว่ากำลังแก้ชิ้นไหน
  3. 3เปิดไฟล์ถัดไป PS ถามว่าจะ Save ไหม: ตอบ No ไฟล์สอนไม่เปลี่ยน
บทถัดไป: เปิด 2_Insert_Robot_and_Layout ซึ่งมี CNC และ Gripper ที่มีกลไกและ Pose ครบ แล้วทุกคนเริ่มบท 2 จากจุดเดียวกัน

ขั้นที่ 12: Placement วาง HP20D ที่ X 1000 หมุน Rz 180

  1. 1เลือก HP20D > Placement Manipulator กดลูกศรขยาย
  2. 2พิมพ์ Rz = 180 ก่อน
  3. 3แล้ว X = 1000
  4. 4Close

ขั้นที่ 13: Mount Tool ติด Gripper ที่ปลายแขน HP20D

  1. 1เลือก HP20D > Robot > Mount Tool แล้วคลิก Gripper ใน tree
  2. 2Frame ของ Gripper = Base Frame (ขึ้นเอง)
  3. 3Mount on = HP20D
  4. 4Frame = TOOLFRAME
  5. 5Apply แล้ว Close
  6. 6Gripper ย้ายไปติดหน้าแปลนหุ่น ขยับตามแขน

ขั้นที่ 14: New Compound Operation (CompOp)

  1. 1แท็บ Operation ลูกศรใต้ New Operation
  2. 2New Compound Operation
  3. 3Name = CompOp
  4. 4Scope = Operation Root
  5. 5OK
ข้อควรจำ: เมนู New Operation รวมทุกชนิด: Object Flow, Device, Pick and Place, Generic Robotic ใช้ซ้ำในบท 4-5 ไฟล์ 4-7 ชื่อ compound ว่า Operation = กล่องเดียวกับ CompOp

ขั้นที่ 15: New Object Flow Operation ให้ Bank (Bank_In)

  1. 1Name = Bank_In
  2. 2Object = Bank (เลือก Bank ก่อนเปิดคำสั่ง)
  3. 3Start Point = ตำแหน่งปัจจุบัน
  4. 4End Point คลิกช่องเขียวแล้วคลิกปลายสายพาน
  5. 5Duration = 5
  6. 6OK
  7. 7ต้นสายพาน loc1 (600, 2559.8, 830)
  8. 8ปลายสายพาน loc (600, 759.8, 830)

ขั้นที่ 16: New Device Operation ประตู CNC (CNC_CLOSE / CNC_OPEN)

  1. 1Name = CNC_CLOSE
  2. 2Device = CNC (เลือกก่อนเปิดคำสั่ง)
  3. 3From pose = OPEN
  4. 4To pose = CLOSE
  5. 5Duration = 3
  6. 6OK
ทำซ้ำ: CNC_OPEN: From CLOSE > To OPEN 3 วินาที CNC จะเป็นสีฟ้าตอนถูกเลือก ค่าเริ่มต้นของ Duration คือ 5 ต้องแก้เป็น 3

ขั้นที่ 17: Set Current Operation, Link แล้วเล่นได้ 11 วินาที

  1. 1ก่อน: Bank_In เริ่มพร้อม CNC_CLOSE (ยังไม่ Link)
  2. 2หลัง: Bank_In 0-5 > CLOSE 5-8 > OPEN 8-11
  3. 3คลิกขวา CompOp > Set Current Operation
  4. 4เลือก Bank_In แล้ว Ctrl+คลิก CNC_CLOSE > ปุ่ม Link
  5. 5เล่นจบ 11.00 วินาที

ปัญหาที่พบบ่อยและวิธีแก้

อาการวิธีแก้
Pose Editor สีเทาชิ้นนั้นยังไม่มี joint: Set Modeling Scope แล้วสร้าง link / joint ก่อน
พิมพ์ค่า j1 แล้วกด Enter ได้ท่า pos1ใช้ Tab แทน Enter แล้วตั้งชื่อ ถ้าได้ pos1 แล้วใช้ Edit... เปลี่ยนชื่อ
ชื่อ Pose ต่อท้ายกัน (pos1OPEN)ในช่อง Pose name กด End แล้ว Shift+Home, Delete ก่อนพิมพ์
Joint Dependency สูตรผิด (cos)กด C ล้างสูตร เปิดรายการ Joint Name เลือก j1 แล้วกดปุ่ม j1
เวลาเล่นมากกว่าในไฟล์หุ่นไม่ได้อยู่ท่า Home: Robot > Home แล้ว Jump Simulation to Start
