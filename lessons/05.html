05. BIW Spot Welding

วัตถุประสงค์การเรียนรู้

  1. สร้างจุดเชื่อมด้วย Weld Point (Preserve จาก SPOT_CD) และฉายจุดลงผิวชิ้นงานด้วย Project
  2. สร้าง Weld Operation (Weld_Op 10 จุด) และใช้ Gun Search เลือกปืนที่เชื่อมได้ครบจาก 14 รุ่น
  3. ติด Fixture และหุ่น S040R03 พร้อมปืนด้วย Mount Tool
  4. ใช้ Pie Chart / WDC ปรับมุมเข้าอัตโนมัติ และตั้ง Start / via ก่อน-หลังจุดเชื่อม
  5. ตรวจ Collision แล้วเพิ่ม via หลบ จากนั้น Mirror ให้หุ่นตัวที่ 2 เชื่อมอีกฝั่ง

งานเชื่อมจุดตัวถังรถ (BIW) ทีละขั้น รวม 25 ขั้น — ตั้งแต่สร้างจุดเชื่อมและเลือกปืน วางจิ๊กและหุ่น ปรับมุมเข้า-ออก ตรวจชน ไปจนถึง Mirror ให้หุ่นอีกตัวเชื่อมอีกฝั่งพร้อมกัน

ภาพรวม: จากจุดเชื่อมถึงหุ่น 2 ตัว

ลำดับหัวข้อทำอะไร
01Weld PointPreserve จุดจาก SPOT_CD แล้วสร้างจุดเชื่อม
02Projectฉายจุดลงผิว PartC ได้ทิศของจุด
03Weld OperationWeld_Op รวม 10 จุด
04Gun Searchปืน 14 รุ่น รุ่นไหนเชื่อมได้ครบ
05Fixture + Robotจิ๊กจับชิ้นงาน หุ่น S040R03 ติดปืน
06Pie Chart / WDCมุมที่ปืนเข้าได้ ปรับมุมอัตโนมัติ
07Approach / DepartStart และ via ก่อน-หลังจุดเชื่อม
08Collisionหาจุดชนแล้วเพิ่ม via หลบ
09Mirrorหุ่นตัวที่ 2 เชื่อมอีกฝั่ง

งานครบในไฟล์ 8: หุ่น 2 ตัวเชื่อมฝั่งละ 10 จุด พร้อมกัน = 62.53 วินาที (อ่านจาก Sequence Editor)

ขั้นที่ 1: ตั้ง System Root แล้วเปิด 1_Weld_Point

  1. 1File
  2. 2Disconnected Study
  3. 3Open in Standard Mode
  4. 4เลือก 1_Weld_Point > Open

ขั้นที่ 2: ไฟล์ 1 มี PartC, PartD และ SPOT_CD (จุดอ้างอิง)

  1. 1Set Modeling Scope
  2. 2ช่อง Scope = SPOT_CD
  3. 3SPOT_CD ชิ้นอ้างอิงจากงานต้นฉบับ
  4. 4Weld_10p จุด point1-10 ที่ใช้

ขั้นที่ 3: Set as Preserved Objects ให้จุด point1-10

  1. 1Shift+คลิก point10 (เลือก 10 จุด)
  2. 2Set as Preserved Objects (แท็บ Modeling กลุ่ม Geometry)
  3. 31 คลิก point1
  4. 4ไอคอนจุดเปลี่ยนเป็นสีเขียว = Preserved

ขั้นที่ 4: Create Weld Points แล้วคลิกจุดสีแดงบนชิ้นงาน

  1. 1แท็บ Process > ปุ่ม Create Weld Points (ไอคอนจุดสีฟ้า)
  2. 2คลิกจุดแดงในหน้าจอ 3D ทีละจุด
  3. 3Home > Mfgs ได้ wp, wp1, ...
  4. 4ตอนทำภาพได้ 9 จุด (ไฟล์ 2 มี 10 จุด)

ขั้นที่ 5: Project Weld Points ฉายจุดลงผิว PartC

  1. 1Project weld points on a customized list of parts
  2. 2ช่องเขียว Parts
  3. 3Obtain Parts แล้วลบ SPOT_CD ให้เหลือ PartC
  4. 4Project
  5. 5ฉายแบบแม่นไม่ผ่าน: ตอบ Yes (ฉายแบบประมาณ)
  6. 6ได้ลูกศรทิศของจุดบนผิว

ขั้นที่ 6: New Weld Operation (Weld_Op) ใส่จุดเชื่อม

  1. 1Robot / Gun ว่างไว้ก่อน (บท 2, 4)
  2. 2Weld List คลิกช่องเขียวแล้วเลือก wp ทั้งหมด
  3. 3OK
  4. 41 Name = Weld_Op
  5. 5Weld_Op มีจุดเชื่อมเรียงตามลำดับ
ระวัง: เลือก Operations (ต้นไม้ล่างซ้าย) ก่อนเปิด Operation > New Operation > New Weld Operation ถ้าเลือก Part เมนูจะเป็นสีเทา ใน Weld List ให้เลือก wp จากต้นไม้ Operations (เลือกจาก Mfgs ขึ้น Invalid Location)

ขั้นที่ 7: Insert Component ปืน 15 รุ่นจาก SPOT_GUN

  1. 1Ctrl+คลิกเลือกปืนหลายรุ่น
  2. 2Open
  3. 31 Modeling > Insert Component > Resource\SPOT_GUN
  4. 4ปืนขึ้นใน Resources

ขั้นที่ 8: Weld_Op > Operation Properties ตั้ง Gun แล้ว Set Current

  1. 1คลิกขวา Weld_Op > Operation Properties > แท็บ Process
  2. 2Gun คลิกช่องแล้วคลิก SPOT_GUN_MAA32963S ใน Objects
  3. 3OK
  4. 4คลิกขวา Weld_Op > Set Current Operation (ต้องมีก่อน Gun Search)

ขั้นที่ 9: Geometric Gun Search เลือกจุดและปืน

  1. 1Process > Geometric Gun Search > Next: จุดของ Weld_Op ขึ้นเอง
  2. 2Select guns from Study > Shift เลือกทุกปืน
  3. 3ปุ่ม >
  4. 4ปืนที่จะทดสอบ

ขั้นที่ 10: ตั้งการตรวจชนแล้ว Search

  1. 1All objects in Study (ชนกับทุกอย่าง)
  2. 2Gun States: Closed + Open
  3. 3Gun Rotation หมุนปืนหาท่า 180° / 90 สเต็ป
  4. 4Next > Search

ขั้นที่ 11: ผล Gun Search: ปืนไหนเชื่อมได้ครบ 10 จุด

  1. 1C_GUN 0 % ชนตั้งแต่ wp
  2. 2100 % = เครื่องหมายถูกทุกจุด
  3. 3tmx_140 0 % / X_GUN 40 %

ขั้นที่ 12: Insert Fixture (MAA28354S + PALLET)

  1. 1Insert Component > Resource\LINE_CD เลือก MAA28354S_BASE ถึง TRANSFER
  2. 2Ctrl+คลิก PALLET
  3. 3Open
  4. 4Fixture ขึ้นที่พื้น (Z 0) ใต้ชิ้นงาน

ขั้นที่ 13: Placement ยก Fixture ขึ้น Z 1267 ให้รับชิ้นงาน

  1. 1เลือกชิ้น Fixture ทั้ง 17 (Shift) > Placement Manipulator > แกน Z
  2. 2พิมพ์ 1267 Enter
  3. 3Close

ขั้นที่ 14: ไฟล์ 4 มี compound Gun, Fixture แล้วใส่หุ่น

  1. 1Gun frame + SPOT_GUN
  2. 2Fixture 17 ชิ้น
  3. 3Gripper / Base จากงานเต็ม (ไม่ใช้)
  4. 4ROBOT_MODEL\irb6650_320
  5. 5Open

ขั้นที่ 15: Placement วาง S040R03 ที่ (2800, -2900, 0) Rz 90

  1. 1Placement Manipulator > ลูกศรขยาย
  2. 2Rz = 90 ก่อน
  3. 3X = 2800
  4. 4Y = -2900
  5. 5ก่อน: จุด 0 ซ้อนใน Fixture
  6. 6หลัง: หันเข้าหาชิ้นงาน

ขั้นที่ 16: Mount Tool ติด SPOT_GUN แล้วตั้ง Robot ให้ Weld_Op

  1. 1S040R03 > Robot > Mount Tool > Tool = SPOT_GUN_MAA32963S
  2. 2Frame = Base Frame
  3. 3Mount on = S040R03
  4. 4TOOLFRAME
  5. 5Apply
  6. 6Weld_Op > Operation Properties > Process > Robot = S040R03

ขั้นที่ 17: Pie Chart ดูช่วงมุมที่ปืนเข้าเชื่อมได้

  1. 1แดง = หุ่นเอื้อมไม่ถึง
  2. 2น้ำเงิน = เข้าได้ (All OK)

ขั้นที่ 18: Automatic Approach Angle ปรับมุมทุกจุดอัตโนมัติ

  1. 1Robot = S040R03
  2. 2Tool = SPOT_GUN
  3. 3Optimal zone
  4. 4ทุกจุดได้ถูก
  5. 5Execute
  6. 6Weld Distribution Center: 30.75 วินาที
  7. 7Assign (10)

ขั้นที่ 19: Add Location Before ได้ via แล้วถอย Z -100

  1. 1เลือก wp (ต้นไม้ Operations) > Operation > Add Location Before ได้ via
  2. 2Robot Jog เปิดเอง: แกน Z ของ TCPF
  3. 3กดลูกศรถอยจน -100
  4. 4Close
ทำซ้ำ: เลือก wp > Add Location After ได้ via1 แล้วถอย -100 เหมือนกันทุกจุด จุดเชื่อมได้คู่ via ก่อน-หลัง (ไฟล์ 6 มี 32 จุด)

ขั้นที่ 20: Start ที่ท่า Home แล้วเรียงให้อยู่หน้าสุด

  1. 1S040R03 > Robot > Home > Add Current Location > F2 = Start
  2. 2Path Editor: Move Up ให้ Start อยู่บนสุด
  3. 3ไฟล์ 5 = 30.75 วินาที
  4. 4เล่นได้ 47.23 วินาที

ขั้นที่ 21: Collision Set: ปืนกับชิ้นงาน + Fixture

  1. 1Check = SPOT_GUN_MAA32963S
  2. 2With = SPOT_CD
  3. 3Fixture
  4. 4OK
  5. 5New Collision Set
  6. 6Edit Collision Set
  7. 7ไฟล์ 6 มี new_collision_set แล้ว

ขั้นที่ 22: Collision Mode แล้วเล่น: ไฟล์ 6 ปืนชนชิ้นงาน

  1. 1ชิ้นที่ชนเป็นสีแดงในหน้าจอ 3D
  2. 2Collision: SPOT_GUN, C, SPOT_CD
  3. 3Home > Collision Mode (สีฟ้า = เปิด)
ระวัง: เปิดไฟล์ใหม่แล้ว Collision Mode จะปิดเอง ต้องกดเปิดอีกครั้งก่อนเล่น ไม่งั้นรายการว่างเหมือนไม่ชน

ขั้นที่ 23: เพิ่ม via หลบ: ไฟล์ 7 ไม่ชนแล้ว (62.39 วินาที)

  1. 1No pairs to display = ไม่มีคู่ที่ชน
  2. 2ไฟล์ 7 เพิ่ม via20-via31 (47 จุด) ระหว่างจุดที่ชน
  3. 3Weld_Op 62.39 วินาที

ขั้นที่ 24: Mirror Operation ได้หุ่นและงานอีกฝั่ง

  1. 1เลือก Weld_Op > Operation > Mirror
  2. 2Weld_Op_mirrored
  3. 3Apply
  4. 4ระนาบกระจก (แกน XZ)
  5. 5ได้ Weld_Op_mirrored

ขั้นที่ 25: Compound Operation: หุ่น 2 ตัวเชื่อมพร้อมกัน 62.53 วินาที

  1. 1CompOp = Weld_Op + Weld_Op_mirrored (ไม่ Link)
  2. 2จบ 62.53 เท่าตัวที่นานสุด
สรุป: New Compound Operation > ลาก Weld_Op และ Weld_Op_mirrored เข้า > Set Current Operation > เล่น สองงานไม่ได้ Link กัน จึงทำพร้อมกัน เวลาไม่บวกกัน

ไฟล์ในบทเรียนและสิ่งที่อยู่ในแต่ละไฟล์

เช็กลิสต์: ผู้เรียนทำได้ครบหรือยัง

ข้อสิ่งที่ต้องทำได้ตรวจด้วย
1Preserve จุด, Create Weld Points, Projectจุดมีลูกศรทิศบนผิว PartC
2New Weld OperationWeld_Op มี 10 จุด
3Gun Search และอ่านผลบอกได้ว่าปืนไหน 100 %
4Insert Fixture / Robot + Placement + Mount Toolปืนติดหุ่น S040R03
5Pie Chart / Automatic Approach Angleทุกจุดเป็นเครื่องหมายถูก
6via ก่อน-หลัง + Startเล่น Weld_Op ได้ครบ
7Collision Set + Collision ModeNo pairs to display
8Mirror + Compoundหุ่น 2 ตัวเชื่อมพร้อมกัน

ปัญหาที่พบบ่อยและวิธีแก้

อาการวิธีแก้
Set as Preserved Objects สีเทาSet Modeling Scope ที่ SPOT_CD ก่อนและเลือกจุดแต่ละตัว (ไม่ใช่ Weld_10p)
Projection on exact part geometry failedตอบ Yes ให้ฉายแบบประมาณ
New Weld Operation สีเทาเลือก Operations ในต้นไม้ล่างซ้ายก่อน
Weld List ขึ้น Invalid Locationเลือก wp จากต้นไม้ Operations ไม่ใช่ Mfgs
Gun Search ไม่มีจุดให้เลือกตั้ง Gun แล้ว Set Current Operation ก่อน
Robot Jog พิมพ์ค่าแล้วไม่ขยับกดลูกศรตาม Step Size แทน
เล่นแล้วไม่มีผลการชนเปิด Collision Mode ใหม่ทุกครั้งที่เปิดไฟล์
Mirror เตือน Missing the assigned robotกด OK แล้วใส่หุ่นตัวที่ 2 ให้ Weld_Op_mirrored
