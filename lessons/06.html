06. Robot Painting

วัตถุประสงค์การเรียนรู้

  1. ติด brush เข้ากับ gun แล้วติด gun ที่ปลายแขนหุ่นด้วย Mount Tool และดู brush ใน Paint Brush Editor
  2. ตั้งรางให้เป็นแกนที่ 7 ของหุ่นด้วย External Axes
  3. สร้างตาข่ายบนผิวชิ้นงานด้วย Create Mesh แล้วสร้างเส้นพ่นไปกลับด้วย Process Generator (6 เส้น)
  4. เล่น simulation เพื่อดู Coverage บนผิว ตรวจ Reach และตั้งสีของ Coverage Settings

งานพ่นสีฝากระโปรงรถด้วยหุ่นบนราง ทีละขั้น รวม 17 ขั้น — ติดหัวพ่น สร้างเส้นพ่นบนผิวชิ้นงาน แล้วดูว่าสีครอบคลุมทั่วหรือไม่

ภาพรวม: ติดหัวพ่นแล้วสร้างเส้นพ่นสีบนฝากระโปรง

ลำดับหัวข้อทำอะไร
01Attachติด brush เข้ากับ gun ก่อน
02Mount Toolติด gun ที่ปลายแขนหุ่น
03Paint Brush Editorbrush ที่หุ่นใช้พ่น
04External Axesให้รางเป็นแกนที่ 7 ของหุ่น
05Create Meshแบ่งผิวชิ้นงานเป็นตาข่าย
06Process Generatorสร้างเส้นพ่นแบบไปกลับ
07Coverageระบายสีบนผิวตอน Play
08Reachหุ่นเอื้อมถึงทุกจุดไหม
09Coverage Settingsสีของจำนวนรอบที่พ่นทับ
สิ่งที่ต้องมี: Process Simulate 2502 · โฟลเดอร์ 06_ROBOT_PAINTING · Library\ (หุ่น ราง gun brush รถ) · 1_ ถึง 3_ .psz

Workflow: 6 ช่วง

02Brush Editorดู brush BrushAsym ของหุ่นบท 1: ไฟล์ 1_
03External AxesAttach หุ่นกับราง + Robot Propertiesบท 1: ไฟล์ 1_
04Create Meshตาข่ายบนผิวรถบท 2: ไฟล์ 2_
05Process Generator6 เส้นพ่นบนฝากระโปรงบท 2: ไฟล์ 2_

ขั้นที่ 1: เปิด 1_Open_Paint_Study ดูของในเซลล์

  1. 1ElevatedRail ราง
  2. 2IRB5500 หุ่นพ่นสี
  3. 3Paint_Gun
  4. 4PaintBrush
  5. 5gun กับ brush ยังวางอยู่ที่พื้นข้างล้อหน้า
  6. 6หุ่นที่ท่า HOME
  7. 71 Painting ชิ้นงาน (ตัวรถ)
  8. 8ราง

ขั้นที่ 2: Attach brush เข้ากับ gun

  1. 1ช่อง Search พิมพ์ Attach
  2. 2Home > Tools > Attachment > Attach
  3. 3Attach Objects: PaintBrush (เลือกไว้ก่อน)
  4. 4One Way
  5. 5To Object: คลิก Paint_Gun ใน tree
  6. 6OK

ขั้นที่ 3: Mount Tool ติด gun ที่ปลายแขนหุ่น

  1. 1เลือกหุ่นใน tree > แท็บ Robot > Mount Tool
  2. 2Tool: คลิก Paint_Gun ใน tree
  3. 3Frame: Base Frame (ขึ้นให้เอง)
  4. 4Mount on: IRB5500_ProArm...
  5. 5Frame: TOOLFRAME
  6. 6Apply (ยังไม่ Close)

ขั้นที่ 4: Flip Tool (X) หมุน gun ทีละ 90° ให้หัวพ่นชี้ลง

  1. 1หลัง Mount: หัวพ่นชี้ไปด้านข้าง
  2. 2ท่าที่ถูก: หัวพ่นและ brush ชี้ลงหาผิวรถ (เหมือนไฟล์ 2_)
  3. 3Flip Tool (X) กด 3 ครั้ง (ครั้งละ 90° รอบแกน X)
  4. 4ลูกศร: เลือกแกน X / Y / Z แล้ว Close

ขั้นที่ 5: Paint Brush Editor ดู brush ของหุ่น

  1. 1เลือกหุ่น > แท็บ Process > Paint Brush Editor
  2. 2ปุ่ม New สร้าง brush ใหม่
  3. 3ปุ่ม Edit (เลือก brush ก่อน)
  4. 4BrushAsym brush ที่มีอยู่แล้ว
  5. 5Brush Name: BrushAsym
  6. 6Solid: Brush_200 (รูปทรงละอองสี)
  7. 7Origin Frame: TIP
  8. 8Cancel ไม่แก้แล้ว Close

ขั้นที่ 6: Attach หุ่นเข้ากับแคร่ของราง (lnk2)

  1. 1เลือกหุ่น > Attach: Attach Objects = หุ่น
  2. 2To Object: lnk2 ของ ElevatedRail
  3. 3OK
  4. 4lnk1 ฐานราง/lnk2 แคร่ที่เลื่อนได้

ขั้นที่ 7: Robot Properties > External Axes > Add

  1. 1Search: Robot Properties > แท็บ External Axes
  2. 2Add...
  3. 3Device: ElevatedRail
  4. 4Joint: j1
  5. 5Name: ElevatedRail:j1
  6. 6OK
  7. 7ขึ้นในรายการ > Close

ขั้นที่ 8: Joint Jog เห็นแกนราง j1 เพิ่มเข้ามา

  1. 1j1 (ElevatedRail) แถวสุดท้าย
  2. 2ช่วง -500 ถึง 1500 mm
  3. 3พิมพ์ 1000 + Tab
  4. 4หุ่นเลื่อนไปตามราง > Reset, Close

ขั้นที่ 9: Create Mesh บนชิ้นงาน Painting

  1. 1เปิด 2_Paint_Gun_Brush > เลือก Painting > Create Mesh
  2. 2Painting ในรายการ
  3. 3เครื่องหมายถูก = มี mesh แล้ว
  4. 4Distance 20 mm
  5. 5Deviation 0.5 mm
  6. 6Angle 15°
  7. 7Preview แล้ว OK
  8. 8Preview: ผิวรถเป็นตาข่าย

ขั้นที่ 10: Mesh เดิมมีแล้ว: Yes เพื่อสร้างใหม่

  1. 1"Mesh already exists ... overwrite?" > Yes
  2. 2"Part Painting: Mesh created successfully"
  3. 3OK แล้ว Close หน้าต่าง Create Mesh

ขั้นที่ 11: Continuous Process Generator เลือก face

  1. 1เลือกหุ่น > Continuous Process Generator · Process: Coverage pattern
  2. 2Faces (ช่องเขียว): คลิกผิวฝากระโปรง > 1 Faces
  3. 3Stroke direction Back and forth
  4. 4Spacing 75 mm

ขั้นที่ 12: Start / End point และจำนวนเส้น

  1. 1คลิกช่อง Start point > คลิกปลายล่างซ้ายของ face
  2. 2คลิกช่อง End point > คลิกปลายบนขวา: ได้ 1 seam
  3. 3Strokes before 3
  4. 4Strokes after 2
  5. 5เส้นสีน้ำเงิน 6 เส้นวิ่งไปกลับ
  6. 6Number of seams: 6

ขั้นที่ 13: Mfg type = PaintContinuousMfg และค่าของ operation

  1. 1Paint_Robotic_Op (เปลี่ยนเอง)
  2. 2Robot: IRB5500
  3. 3Tool: Paint_Gun
  4. 4Mfg type: PaintContinuousMfg
  5. 53D folder: Library\mfg
  6. 6Tangent ZigZag
  7. 7Traverse 150 mm
  8. 8OK

ขั้นที่ 14: ได้ Paint_Robotic_Op 6 operation

  1. 1จุดพ่นบนผิวฝากระโปรง
  2. 2Paint_Robotic_Op (compound)
  3. 3Paint_Robotic_Op_1 ถึง
  4. 4_6 = 1 เส้นต่อ 1 op

ขั้นที่ 15: เปิด Coverage During Simulation

  1. 1แท็บ Process > ลูกศรของ Paint During Simulation
  2. 2Coverage During Simulation (ปุ่มเป็นสีฟ้า)
  3. 3Paint and Coverage Settings: ติ๊ก Coverage
  4. 4ติ๊ก Brush (เห็นละอองสี)
  5. 5Color Scale: สีตามจำนวนรอบที่พ่นทับ 1 ถึง 9+
  6. 6เลือก Paint_Robotic_Op > Operation > Set Current Operation

ขั้นที่ 16: Reach: หุ่นเอื้อมไม่ถึงจุดของเส้นใหม่

  1. 1Play ไฟล์ 2_ ที่สร้างเอง: may not reach Paint_Robotic_Op_1_ls2
  2. 2แก้ได้ด้วย Rotation / External Axes / Configuration

ขั้นที่ 17: Play ไฟล์ 3_Coverage_Pattern ดูสีบนผิว

  1. 1ละอองสี (brush) ลงบนผิวตามเส้น
  2. 2พ่นครบ 6 เส้นสีน้ำเงิน = พ่น 1 รอบ
  3. 3Sequence Editor: 6 op ต่อกันรวม 22.75 วินาที

ไฟล์ในบทเรียนและสิ่งที่อยู่ในแต่ละไฟล์

ไฟล์สิ่งที่มี
1_Open_Paint_Study.pszเริ่มบท 1: รางหุ่น gun brush รถ (gun กับ brush วางที่พื้น)
2_Paint_Gun_Brush.pszเฉลยบท 1 / เริ่มบท 2: gun mount, brush attach, หุ่น attach lnk2, External Axis j1, mesh 20 mm
3_Coverage_Pattern.pszเฉลยบท 2: Paint_Robotic_Op 6 op (5 จุดต่อเส้น) + via, ฐานหุ่น+100 mm
Library\resource\elevatedrail, irb5500_proarm, paint_gun, paintbrush, paint_room
Library\Part\ และ mfg\Painting (รถ) และเส้น Paint_Robotic_Op_1 ถึง 6

เช็กลิสต์: ผู้เรียนทำได้ครบหรือยัง

ข้อสิ่งที่ต้องทำได้ตรวจด้วย

3Attach หุ่นกับ lnk2 + External AxesJoint Jog มี j1 หุ่นเลื่อนตามราง

ปัญหาที่พบบ่อยและวิธีแก้

อาการวิธีแก้
Mount แล้ว brush ยังอยู่ที่พื้นAttach brush กับ gun ก่อน Mount (Undo ไม่คืนการ Mount ให้เปิดไฟล์ใหม่)
Mount แล้วหัวพ่นชี้ผิดทางFlip Tool (X) ในหน้าต่าง Mount Tool ครั้งละ 90° (ไฟล์นี้ 3 ครั้ง)
หาปุ่ม Attach / Robot Properties ไม่เจอพิมพ์ในช่อง Search มุมขวาบนแล้วคลิกผลลัพธ์
Paint Brush Editor สีเทาเลือกหุ่นก่อน (ไม่ใช่ gun)
Relocate หาเฟรมของ gun ไม่ได้ลิสต์ To frame มีแค่ Self / Geometric center / Working frame ใช้วิธี Attach แทน
Process Generator ขึ้น Faces are missingคลิกผิวในจอ 3D ตอนช่อง Faces เป็นสีเขียว
Play แล้วขึ้น Dynamic Reach Advisorจุดไกลเกิน: ขยับฐาน/ใช้ External Axes / ลดจุดหรือเปิดไฟล์ 3_
