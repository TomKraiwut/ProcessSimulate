07. Robot Press Line

วัตถุประสงค์การเรียนรู้

  1. เปิดไฟล์แล้ว Save As ทำสำเนาก่อนลอง และเลือกหุ่น Robot_1 ที่อยู่หน้าเครื่อง Press_500T_1
  2. ตั้งค่า Smart Place: Locations (pick / place) และ Search Area ตาราง 9 × 9 จุดรอบหุ่น
  3. กด Start แล้วอ่านสีของแต่ละจุด (ถึงทั้ง pick และ place / ถึงแต่ชน)
  4. ย้ายหุ่นไปจุดที่เหมาะสมด้วย Place แล้วคืนหุ่นด้วย Reset

หาตำแหน่งวางหุ่นที่เอื้อมถึงทุกจุดด้วย Smart Place ในไลน์ปั๊ม — ทีละขั้น รวม 9 ขั้น ให้ PS ทดสอบทุกจุดรอบหุ่นแล้วเลือกจุดที่ใช้ได้

ผลในตัวอย่าง: จาก 81 จุดที่ทดสอบ มี 28 จุด ที่ Robot_1 ยืนแล้วเอื้อมถึงทั้ง pick และ place

ขั้นที่ 1: Save As เป็นไฟล์ใหม่ 1_Smart_Place

  1. 1File
  2. 2Disconnected Study
  3. 3Save As...
  4. 4โฟลเดอร์ 07_ROBOT_PRESS_LINE
  5. 5File name = 1_Smart_Place
  6. 6Save

ขั้นที่ 2: เลือก Robot_1 แล้วเปิด Robot > Smart Place

  1. 1Objects > Resources > Step1
  2. 2คลิก Robot_1
  3. 3แท็บ Robot
  4. 4กลุ่ม Reach > Smart Place

ขั้นที่ 3: หน้าต่าง Smart Place แบบ Robot Placement

  1. 1Robot Placement (หาที่วางหุ่น)
  2. 2Robot = Robot_1 ขึ้นให้เอง
  3. 3ช่อง Locations สีเขียว = รอให้คลิกจุด
  4. 4Search Area พื้นที่ที่จะลองวางหุ่น
  5. 5Start ยังกดไม่ได้จนกว่าจะมี Location

ขั้นที่ 4: ใส่ pick และ place ของ Robot_1 ลง Locations

  1. 1Operations > Simulation > Robot > กาง Robot_1
  2. 2คลิก pick
  3. 3คลิก place
  4. 4สองจุดขึ้นในรายการ Locations

ขั้นที่ 5: Search Area ค่าเริ่มต้น + ติ๊ก Partial Reach แล้ว Start

  1. 1Grid: 9 = 9 จุดต่อแกน (คลิกเพื่อแก้)
  2. 2-2000 ถึง
  3. 32000 mm รอบตำแหน่งหุ่น (X และ Y)
  4. 4ติ๊ก Partial Reach
  5. 5ไม่ติ๊ก Collision (ดูขั้นที่ 9)
  6. 6Start ใช้เวลาไม่เกิน 20 วินาที

ขั้นที่ 6: อ่านผล: Solutions Found 28 จุด

  1. 1Solutions Found: 28 = จุดน้ำเงิน
  2. 2ช่องกลาง = ตำแหน่งเดิมของหุ่นเป็นสีน้ำเงิน
สรุป: Robot_1 ยืนที่เดิมเอื้อมถึงทั้ง pick และ place และยังย้ายได้อีก 27 ตำแหน่ง ส่วนใหญ่ไปทางเครื่องปั๊ม (ขวา)

ขั้นที่ 7: คลิกจุดน้ำเงินแล้ว Place หุ่นย้ายไปจุดนั้น

  1. 1คลิกจุดสีน้ำเงิน (ได้เครื่องหมาย X)
  2. 2Place At = ชื่อจุดเช่น point7-6-1
  3. 3Place
  4. 4หุ่นไปยืนที่จุดใหม่ ยังเอื้อมถึงเครื่องปั๊ม
  5. 5Base_Robot_1 ไม่ย้ายตาม (คนละชิ้น)

ขั้นที่ 8: Reset หุ่นกลับขึ้นฐานแล้ว Close

  1. 1หุ่นกลับขึ้นยืนบน Base_Robot_1 ตามเดิม
  2. 2Reset คืนตำแหน่งตอนเปิดหน้าต่าง
  3. 3Close
ระวัง: ถ้าปิดโดยไม่ Reset หุ่นจะค้างที่จุดใหม่โดยไม่มีฐาน ถ้าเผลอบันทึกให้เปิดไฟล์ Completed แล้ว Save As ใหม่

ขั้นที่ 9: ติ๊ก Collision แล้วได้ 0 จุด (ถึงแต่ชน)

  1. 1Solutions Found: 0
  2. 2จุดที่ถึงเป็นสีส้มทั้งหมด รวมตำแหน่งเดิม
  3. 3Collision Viewer มี new_collision_set เปิดอยู่

เช็กลิสต์: ผู้เรียนทำได้ครบหรือยัง

ข้อสิ่งที่ต้องทำได้ตรวจด้วย
1Save As เป็นไฟล์ใหม่แถบหัวขึ้น 1_Smart_Place.psz
2เปิด Smart Place กับ Robot_1ช่อง Robot = Robot_1
3ใส่ pick และ placeLocations มี 2 รายการ
4ตั้ง Search Area แล้ว StartSolutions Found 28
5อ่านสี 4 แบบบอกได้ว่าน้ำเงิน/ส้มคืออะไร
6Place และ Resetหุ่นกลับขึ้นฐานเดิม

ปัญหาที่พบบ่อยและวิธีแก้

อาการวิธีแก้
Start กดไม่ได้ใส่ Location อย่างน้อย 1 จุด (ช่องสีเขียว)
คลิกจุดใน Operations ไม่ได้หน้าต่าง Smart Place บังอยู่ ลากไปด้านข้างก่อน
Solutions Found 0 ทุกจุดสีส้มเอาติ๊ก Collision ออก หรือดู collision set ใน Collision Viewer
มองไม่เห็นหุ่นย้ายลากหน้าต่างออกแล้วซูมที่ Step1
หุ่นลอยไม่มีฐานหลัง Placeปกติฐานเป็นคนละชิ้น กด Reset
หาปุ่ม Smart Place ไม่เจออยู่ที่แท็บ Robot กลุ่ม Reach (บางเวอร์ชันเรียกกลุ่ม Tools)
