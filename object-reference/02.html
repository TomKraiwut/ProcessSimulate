Process Simulate Tutorial

2. Operation Objects

วัตถุประสงค์การเรียนรู้

  1. เข้าใจว่า Operation แต่ละประเภทมีไว้ทำอะไร
  2. รู้ว่าจะไปดูรายละเอียดเชิงลึกของแต่ละตัวต่อได้จากบทไหน

Operation แต่ละประเภท

Operationหน้าที่ดูรายละเอียดเพิ่มที่
Pick / Placeหยิบและวางชิ้นงาน — Operation พื้นฐานที่สุดBasic บทที่ 4
Weld Pointเชื่อมเป็นจุด (Spot Weld)Intermediate บทที่ 3
Weld Lineเชื่อมต่อเนื่องเป็นเส้น (Seam/Arc Weld)Intermediate บทที่ 3
Paste / Sealingปาดกาวหรือฉีดวัสดุตามแนวเส้นทางที่กำหนด คล้าย Weld Line แต่ปล่อยวัสดุแทนกระแสไฟCase Study บทที่ 1
Human Operationงานที่ Human Resource ทำ เช่น เดินไปหยิบ-วางหรือประกอบชิ้นงานAdvanced บทที่ 5
ลองสาธิต: เปิด Study เดิมที่มี Operation Pick/Place จากบท Basic 4 แล้วลองสร้าง Weld Point Operation เพิ่มในเซลล์เดียวกัน สังเกตว่า Attribute ที่ต้องตั้งต่างจาก Pick/Place อย่างไรบ้าง
