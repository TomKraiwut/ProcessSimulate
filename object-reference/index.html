Object Reference — สาธิต Object

รวม Object ที่ใช้บ่อยเป็นหมวดหมู่ พร้อมสาธิตการทำงานสั้นๆ ที่ลองทำตามได้ทันที — ใช้เป็นที่เปิดหาอ้างอิงเร็วๆ เวลาจำไม่ได้ว่า Object ไหนใช้ทำอะไร

1

Resource Objects

Robot, Device, Fixture, Tool/Gripper — Resource ที่ใช้บ่อยที่สุด
2

Operation Objects

Pick, Place, Weld Point, Weld Line, Paste, Human Operation
3

Logic & Analysis Objects

Logic Block, Signal, Collision Set, PERT chart, Sequence Editor
