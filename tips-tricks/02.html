2. การสร้างโมเดลและดีบัก

วัตถุประสงค์การเรียนรู้

  1. รู้ข้อผิดพลาดที่มือใหม่เจอบ่อย และวิธีเช็คให้ไวก่อนเสียเวลาไล่บั๊กผิดจุด

ข้อผิดพลาดที่มือใหม่เจอบ่อย

อาการสาเหตุที่พบบ่อย
ชิ้นงานไม่เคลื่อนที่ตามหุ่นยนต์ลืมสั่ง Attach ใน Operation Pick (ดู Basic บทที่ 4)
ผลจำลองรอบใหม่คลาดเคลื่อนจากรอบก่อนลืมกด Reset ก่อนรันใหม่ ทำให้ Pose/Attach ค้างจากรอบก่อนหน้า (ดู Basic บทที่ 5)
หุ่นยนต์หยิบ-วางพลาดตำแหน่งหลังเปลี่ยน Gripperลืมปรับ ExtTcp ให้ตรงกับ Tool ตัวใหม่ (ดู Intermediate บทที่ 2)
Collision Report เต็มไปด้วยรายการไม่เกี่ยวข้องยังไม่ได้จัด Collision Set แยกเฉพาะคู่ที่เสี่ยงจริง (ดู Intermediate บทที่ 5)
ข้อควรระวัง: เมื่อโมเดลพฤติกรรมแปลกๆ ให้เช็ค 4 จุดนี้ก่อนไล่ดีบักลึกกว่านั้น เพราะเป็นสาเหตุที่พบบ่อยที่สุด สำหรับคนที่เพิ่งเริ่มใช้โปรแกรม
