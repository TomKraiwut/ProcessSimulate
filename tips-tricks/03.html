3. ประสิทธิภาพการรัน (Performance)

วัตถุประสงค์การเรียนรู้

  1. รู้เทคนิคที่ช่วยให้เซลล์ขนาดใหญ่รันเร็วขึ้นโดยไม่กระทบผลลัพธ์

เทคนิคทำให้เซลล์ขนาดใหญ่รันเร็วขึ้น

  • ปิดการแสดงผลกราฟิกรายละเอียดสูง (เช่น Texture, Shadow) ระหว่างทดสอบ Path บ่อยๆ แล้วเปิดกลับตอนต้องการดูผลจริง
  • จำกัด Collision Set ให้เหลือเฉพาะคู่ Object ที่เสี่ยงชนจริง แทนการเช็คทุก Object กับทุก Object ในเซลล์ (ดู Intermediate บทที่ 5)
  • ปิดหรือซ่อน Resource ที่ไม่เกี่ยวข้องกับ Operation ที่กำลังทดสอบ ลดภาระการคำนวณ Collision ที่ไม่จำเป็น
Tip: เมื่อต้องทดสอบ Path ซ้ำๆ ระหว่างปรับ Pose ให้เปิด Dynamic Collision Detection เฉพาะ Object ที่กำลังแก้ไข แล้วค่อยเปิดเช็คแบบเต็มเซลล์อีกครั้งก่อนสรุปผล จะประหยัดเวลารอผลระหว่างขั้นตอนปรับละเอียดได้มาก
