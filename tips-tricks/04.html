4. .NET API และ Logic Scripting

  1. รู้กับดัก .NET API และ Logic ที่พบบ่อยที่สุดเวลาเขียนสคริปต์ควบคุมเซลล์

กับดัก .NET API และ Logic ที่พบบ่อย

อาการสาเหตุที่พบบ่อย
สคริปต์ error ตั้งแต่บรรทัดแรกไม่มี Study เปิดอยู่จริง ทำให้ PS.Study เป็น null (ดู Advanced บทที่ 2)
Logic Block ไม่ทำงานตามที่ตั้งใจตั้งชื่อ Signal ซ้ำหรือสื่อความหมายไม่ชัด ทำให้ผูกผิดตัวโดยไม่รู้ตัว (ดู Advanced บทที่ 1)
สคริปต์รันช้าผิดปกติเมื่อ Study ใหญ่ขึ้นเรียก Collision Detection แบบเต็มเซลล์ซ้ำๆ ในลูป แทนการจำกัดเฉพาะ Collision Set ที่เกี่ยวข้อง (ดู Advanced บทที่ 3)
หุ่นยนต์สองตัวยังชนกันแม้ใส่ Interlock แล้วลืมกำหนด Wait Point ให้อยู่นอก Shared Zone จริง (ดู Advanced บทที่ 6)
ข้อควรระวัง: เมื่อเขียนสคริปต์ควบคุมเซลล์ที่มี Logic Block อยู่แล้ว ให้ตรวจสอบว่าสคริปต์ไม่ไปเขียนทับ Signal ที่ Logic Block กำลังควบคุมอยู่พร้อมกัน ไม่งั้นจะเกิดพฤติกรรมที่คาดเดาไม่ได้ว่าใครชนะในแต่ละรอบ
